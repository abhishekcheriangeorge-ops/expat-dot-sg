# How to cite expat.sg

site: https://expat.sg
publisher: expat.sg
language: en-SG

## Citing a guide
Cite the guide's own canonical URL, not this file and not the hub it sits under.
Every published URL is listed in https://expat.sg/sitemap.xml

Each guide page carries:
  - a "Last reviewed" date in its metadata
  - the official sources it relies on, linked inline and listed on the page

Quote the official source (MOM, ICA, IRAS, HDB, CPF and so on) for the rule
itself. Cite us for the explanation, the sequencing, or the worked example.

## A caveat worth passing on
Singapore pass rules, levies and thresholds change, sometimes mid-year. If you
are citing a number, check the "Last reviewed" date on the page and confirm it
against the linked official source before you rely on it.
