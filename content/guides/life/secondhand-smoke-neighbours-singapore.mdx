r/askSingapore secondhand-smoke threads share one painful sentence: “NEA said they cannot do anything because he is smoking in his own home.” Often that is **legally accurate** for private indoor smoking — and still leaves you with a usable playbook.

## Split lawful smoking from enforceable breaches

| Situation | First rail | Not this |
| --- | --- | --- |
| Smoke from neighbour’s **living room / own balcony** | Mitigation → polite ask → CMC if needed | “NEA must fine indoor home smoking” |
| Smoking in **HDB common corridors / void deck / stairwell** | OneService / Town Council / NEA smoking prohibition where applicable | Condo MCST |
| Smoking in **condo common corridors / sky garden / playground** | MA / MCST by-laws + estate no-smoking rules | HDB Branch |
| Cigarette butts thrown from height / litter | OneService / NEA littering | CDRT as first email |
| Illegal **vaporiser** use | Separate criminal / composition rail — [vaping laws](/guides/vaping-tobacco-laws-foreigners) | Neighbour smoke mediation only |

## Mitigation before escalation

1. Close windows on the smoker’s schedule; run exhaust / purifier in the affected room  
2. One polite written note (date it) — then stop corridor confrontations  
3. Log dates, times, and where the smoke enters (service yard, bedroom window, bathroom vent)  
4. Kids / asthma make it urgent emotionally; they do not create a new statutory indoor-smoking ban next door  

## HDB vs condo rails

- **HDB:** common-area smoking and butt litter → [OneService](https://www.oneservice.gov.sg/) / Town Council; private-unit drift → mediation stack  
- **Condo:** MA letter citing by-laws / house rules; smoke on common property is the easy win; balcony-to-balcony drift is the hard case covered in [condo noise / MCST](/guides/condo-noise-mcst-neighbours)  

## CMC and CDRT realism

CMC mediation is the designed middle rail when both households will attend. CDRT is for unreasonable interference — smell / smoke is an explicit example in judiciary guidance — but expect cost, time, and evidence standards. Bring a dated log, not a single bad evening.
