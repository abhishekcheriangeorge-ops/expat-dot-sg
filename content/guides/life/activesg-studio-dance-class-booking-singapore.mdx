Studio threads are rarely about choreography. They are about **who refreshed MyActiveSG+ at release** and whether the condo “multi-purpose room” still has a usable floor. This guide is **ActiveSG studio / dance class booking** for foreigners — distinct from gym entry, badminton, table tennis, squash, tennis, football/futsal, stadium tracks, and pool lanes, and narrower than the climate overview ([sports & fitness](/guides/sports-fitness-singapore)).

## What you are booking

| SKU flavour | Watch-outs |
| --- | --- |
| Instructor-led dance / fitness class | Capacity caps; level tags |
| Empty studio / MPH room hire | Deposit and overtime rules where offered |
| Peak evening slot | Release-time competition |

## Foreigner playbook

1. Singpass → MyActiveSG+  
2. Confirm **Standard Rate**, not a friend’s SC/PR screenshot  
3. Filter for **studio / dance / programme** sessions at your centre  
4. Learn the **release time**; set an alarm  
5. Book, screenshot confirmation, pack attire  
6. Cancel early if you bail  

Before Singpass, call the centre about counter payment. Week-one apps: [apps that matter](/guides/apps-that-matter-singapore).

## Class etiquette that keeps you welcome

- Non-marking indoor shoes unless the instructor says barefoot  
- Arrive inside the grace window — late entry is often refused  
- Dress for the AC–outdoor swing — [what to wear](/guides/what-to-wear-singapore-climate)  
- Social classes beat solitary mall walks for belonging — [dating & social](/guides/dating-social-singapore)  
- Pair with a cultural night so the week is not only work — [arts & culture](/guides/arts-culture-singapore)  

## Condo studio math

Many central condos sell a “dance studio” and deliver a mirrored storeroom. Run a four-week experiment: ActiveSG Standard Rate vs the rent premium you paid for “facilities.”

Catchments around [Orchard](/neighbourhoods/orchard), [Somerset](/neighbourhoods/somerset), and [Dhoby Ghaut](/neighbourhoods/dhoby-ghaut) sit near a dense band of ActiveSG / community centres — test a midweek lunch class before you assume the condo studio is real.
