The MA posts an “LPS / earth-pit inspection”; someone assumes it is a genset test; someone else clears the balcony for a gondola that never arrives. This guide is **condo lightning-protection / earth-pit inspection notice ops** for tenants — not [standby generator / ATS testing](/guides/condo-standby-generator-ats-testing-notices-tenants), not [facade / gondola access](/guides/condo-facade-gondola-access-notices-tenants), and not [fire-alarm / smoke-detector drills](/guides/condo-fire-alarm-smoke-detector-drills-tenants).

## What usually sits where

| Item | Typical owner | Tenant move |
| --- | --- | --- |
| LPS / earth-pit inspection | MCST common property | Read notice; clear named access edges |
| Roof / finial / bonding checks | Specialist contractor via MA | Do not “help” on the roof |
| Generator / ATS test | Separate electrical product | See generator/ATS guide |
| Facade / gondola programme | Separate common-property product | See facade guide |
| Personal storm habits | Household | See thunderstorms living guide |

## Pre-move / pre-LOI questions

1. How often does the estate run **LPS / earth-pit** inspections?  
2. Does any notice require **balcony or grille** clearance?  
3. How are **roof / common-corridor** closures communicated?  
4. Who do you write if access overruns into quiet hours?  
5. How do notices interact with **WFH / helper rest-day** calendars?  

Capture answers before you LOI — same discipline as [renting process](/guides/renting-process-loi-ta-deposits). Personal storm literacy still sits in [lightning & thunderstorms](/guides/lightning-thunderstorms-singapore).

## Ops playbook

- Treat circulars as hard calendars — clear only what the notice names  
- Photograph balcony/ledge condition if temporary clearance is required  
- Do not confuse LPS crews with genset or gondola teams  
- Pair drill confusion with [fire-alarm drills](/guides/condo-fire-alarm-smoke-detector-drills-tenants) only when sirens are involved  
- Write the MA the same day if access windows overrun  

Catchments around [Siglap Fringe](/neighbourhoods/siglap-fringe), [Frankel East](/neighbourhoods/frankel-east), and [Opera Estate West](/neighbourhoods/opera-estate-west) mix mid-rise and landed-edge stock with different LPS calendars — assume MA forms differ by estate, not by MRT stop. By-law orientation: [MCST by-laws / AGM](/guides/condo-mcst-bylaws-agm-tenants).
