The MA WhatsApps a gondola schedule; pots must leave the ledge by 8am; someone assumes it is “just another reno.” This guide is **condo facade / gondola access notice ops** for tenants — not [fire-hose / landing-hydrant clearance](/guides/condo-fire-hose-landing-hydrant-clearance-tenants), not [adjacent unit reno](/guides/condo-unit-renovation-adjacent-tenants), and not the full [MCST by-law / AGM orientation](/guides/condo-mcst-bylaws-agm-tenants).

## What usually sits where

| Item | Typical owner | Tenant move |
| --- | --- | --- |
| Facade / BMU / gondola programme | MCST common property | Read notice; clear balcony edge |
| Balcony pots / racks / laundry | Occupying unit | Move inside the notice window |
| Window / grille internal access | Only if notice says so | Confirm in writing before unlocking |
| Damage claims | MA vs contractor path | Photo before / after |
| Unit reno noise next door | Separate product | See adjacent-reno guide |

## Pre-move / pre-LOI questions

1. How often does the estate run **facade / gondola** programmes?  
2. What must be cleared from **balconies and ledges**?  
3. Does any work require **internal window access**?  
4. How are **damage claims** filed with the MA?  
5. How do notices interact with **WFO / helper rest-day** calendars?  

Capture answers before you LOI — same discipline as [renting process](/guides/renting-process-loi-ta-deposits). Access fights still sit in [landlord entry / quiet enjoyment](/guides/landlord-entry-quiet-enjoyment).

## Ops playbook

- Treat circulars as hard calendars — clear ledges before the boom arrives  
- Photograph balcony condition the evening before and after each drop  
- Do not open windows for crews unless the written notice requires it  
- Pair mould / seep follow-ups after washing with [mould & humidity](/guides/mould-humidity-rental-tenants)  
- Pair corridor equipment rules with [hydrant clearance](/guides/condo-fire-hose-landing-hydrant-clearance-tenants) only when notices confuse the two  

Catchments around [Kaki Bukit Fringe](/neighbourhoods/kaki-bukit-fringe), [Eunos North](/neighbourhoods/eunos-north), and [Paya Lebar West](/neighbourhoods/paya-lebar-west) mix mid-rise and high-rise stock with different BMU calendars — assume MA forms differ by estate, not by MRT stop.
