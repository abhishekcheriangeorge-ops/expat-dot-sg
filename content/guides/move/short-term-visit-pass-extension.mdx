**Short answer:** Extend an **ICA** Short-Term Visit Pass **online** when ≤**14 days** remain — usually ~**5 working days** to process — or **leave** before expiry. Do **not** work on a visit pass, and do **not** treat a JB “visa run” as a plan. MOM’s post-cancellation STVP is a different rail.

Two different “STVP” stories collide on Reddit. This page is about **ICA Short-Term Visit Pass / social visit stay** — the stamp or digital visit pass you hold as a visitor — when your EP, S Pass, or Student’s Pass paperwork is not ready yet. The other story is **MOM’s short-term visit facility after a work pass is cancelled**; that lives in [between jobs on EP](/guides/between-jobs-stvp-singapore).

## Never overstay

Overstaying is an immigration offence. Forum folklore about “waiting quietly for IPA approval past day 30” is how people collect bans, not how they save on flights. If your visit pass ends before formalities, you either:

1. **Extend** via ICA’s published short-stay extension process, or  
2. **Leave** Singapore lawfully and return when your pass / visa position is clean  

<OfficialSource>
Use [ICA — Seeking Extension of Visit Pass](https://www.ica.gov.sg/enter-transit-depart/extend-stay) (same product as the older extend-short-stay URL). Treat every Reddit “I just went to JB for the weekend” tip as hostile to your file.
</OfficialSource>

## How extension usually works (visitor)

| Point | Reality check |
| --- | --- |
| Channel | ICA **online** e-Service only — walk-ins not accepted |
| Timing | Apply when STVP has **≤14 days** remaining — not after overstay |
| Processing | Usually **~5 working days** (excludes weekends/PHs); some take longer |
| Docs | Passport particulars page + **D/E number** from SG Arrival Card; local **SC/PR sponsor ≥21 with Singpass** when required |
| Outcome | Approval is discretionary; length varies — no “auto +14” folklore |
| Purpose field | State the real reason (e.g. awaiting Student’s Pass appointment / EP issuance) without inventing employment |

If ICA refuses, the lawful answer is departure planning — not a second attempt through a land checkpoint the same afternoon.

## Why visa runs backfire

r/askSingapore regularly warns that hopping to Johor for 48 hours to “refresh” a visit pass is a classic pattern ICA systems already know — especially when someone is stretching stay while seeking work. Even when a re-entry happens, you can still be questioned, given a shorter visit, or refused. Pair this with [short-term vs long-term rental](/guides/short-term-vs-long-term-rental): unlawful housing plus visit-pass games is a terrible combination.

## Waiting for a work or student pass

| Scenario | Cleaner approach |
| --- | --- |
| EP IPA approved, card not issued yet | Coordinate with employer on issuance / entry requirements; extend visit only if ICA still needs you here |
| EP still pending | Extension **or** wait overseas — do not work while on a visit pass |
| Student’s Pass appointment after visit expiry | Extend citing the appointment; keep SOLAR / school letters ready — [Student’s Pass](/guides/student-pass-singapore) |
| Pass cancelled after resignation | Different rail — employer-requested MOM STVP up to published limits — [between-jobs STVP](/guides/between-jobs-stvp-singapore) |

Working on a visit pass while “HR said it’s fine” is still illegal work.

## Housing while you wait

Visit-pass status does not legalise a 30-day Airbnb in a private condo. Use hotels / serviced apartments or other lawful short stays — [first housing](/guides/first-housing-serviced-apartment) — and only sign long leases you can actually honour if the pass falls through.

## Practical checklist

1. Screenshot / save your current visit pass expiry the day you land  
2. Diary the **≤14-day** ICA extension window and ~**5 working-day** processing buffer  
3. Keep IPA / school appointment PDFs + SG Arrival Card **D/E number** ready  
4. Line up a local SC/PR sponsor (≥21, Singpass) if your case needs one  
5. Tell HR/school the immigration date in writing so they stop assuming you can “just stay”  
6. If refused, buy the exit ticket — argue from compliance, not from overstay

Visit-pass admin is boring until it is career-ending. Extend online on ICA’s clock, or leave cleanly.
