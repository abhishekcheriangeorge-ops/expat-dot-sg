**Short answer:** Address/mobile updates are a **5-day pass-holder** clock. **Salary and occupation** updates are mostly **employer** clocks — and a salary cut can yank the family’s DP/LTVP. Do not treat a quiet payroll change as invisible to MOM.

This guide sits beside [address / passport / mobile notify](/guides/ep-notify-mom-address-passport). Job hops to an unrelated employer stay on [changing jobs on EP](/guides/changing-jobs-employment-pass).

## Lowering salary — the high-risk path

MOM’s notify page:

| Rule | Detail |
| --- | --- |
| Who notifies | **Employer** |
| Timing | Submit **at least 1 month before** the intended lower-salary date |
| Qualifying test | Revised salary must still qualify for the current pass — run [SAT](https://www.mom.gov.sg/eservices/services/employment-s-pass-self-assessment-tool) |
| If it fails | Cancel the pass and apply for a new pass the person can hold |
| Family cascade | If revised salary fails DP/LTVP privilege criteria, MOM **revokes** existing DP/LTVP tied to the pass |

r/askSingapore salary↔NOA mismatches during renewal are a different (Next-owned) theatre. The living rule while the pass is active: **declared MOM salary is a floor HR must honour**, and reductions need the formal notify — not a handshake.

## Raising salary

- **Raise alone:** MOM does **not** require immediate notification; indicate the change at **EP renewal**.  
- **Raise → dependants:** Pass holders who increase salary must **notify MOM before applying for dependant privileges**.

Package math for how fixed monthly salary is defined still lives on [decoding the offer](/guides/decoding-job-offer-singapore) and [salary package decoding](/guides/salary-package-decoding).

## Occupation change

Employer path:

1. Submit the occupation-update request in MOM’s channel.  
2. Pick the closest match from MOM’s A–Z standard occupations.  
3. Upload professional-body support letters when the occupation requires them.  
4. Expect email outcome within about **3 weeks**.

If the original EP needed **Shortage Occupation List (C5)** COMPASS points, MOM may contact the employer before any fresh application for re-assessment — do not silently refile.

## Related-company transfer vs true job change

| Scenario | What MOM expects |
| --- | --- |
| Branch / subsidiary / affiliate | Related company files a **new EP** (no MyCareersFuture ad). Current employer **cancels** before the new pass can be **issued**. |
| Unrelated new employer | Full [job-change](/guides/changing-jobs-employment-pass) playbook — resign after IPA. |
| Merger / entity change / new UEN | Different “change in business entity” notify — not a personal transfer letter. |

## Candidate checklist (what to ask HR in writing)

1. Will this payroll change be filed as a **MOM salary notify**, and on what date?  
2. Does the revised fixed monthly salary still clear **SAT** at my age / sector band?  
3. Are any **DP / LTVP** holders on my pass — and have you checked privilege criteria?  
4. Is this an occupation rename, a COMPASS-sensitive C5 role, or a related-company move?  
5. Will IRAS / payroll docs (IR8A, payslips) stay consistent with what MOM sees?
