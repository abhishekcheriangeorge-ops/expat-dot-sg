Reddit’s classic landing-week travel mistake: treat **IPA like a passport stamp** and book a JB food trip or regional kickoff while MOM issuance is still open.

## What each document actually is

| Document | What it proves | Travel caution |
| --- | --- | --- |
| **IPA** | In-principle approval for a work pass | Not a finished pass; not a blanket re-entry guarantee |
| **Notification Letter** | Employer completed key issuance steps | Carry it; still confirm ICA/airline path |
| **Physical card / SGWorkPass** | Pass is issued | Normal work-travel baseline for most EP/S Pass holders |

## Before you book

1. Ask HR which MOM issuance steps are still open (medical, biometrics, card).
2. Ask in writing whether you are cleared to **leave and return** on your current status.
3. File the correct [SG Arrival Card](/guides/sg-arrival-card-expats) path for the trip you are actually making.
4. Keep HR’s emergency contact reachable across time zones.

## Safer pattern

Finish [issuance / EPSC / Notification](/guides/work-pass-issuance-epsc-notification) first. Then travel. Mid-issuance tourism is how clean IPA files become messy entry interviews.
