r/askSingapore’s “HR ghosted my WFH email” threads skip the artefact that matters: a **formal FWA request** and a **written reply within two months**. How to file and what rejection can say live on [flexible work arrangement request](/guides/flexible-work-arrangement-request). This companion is the **process-failure → TAFEP** layer for EP / S Pass employees.

TG-FWAR does **not** force approval. It forces proper consideration and a written decision.

## Escalation sequence that matches the Guidelines

| Step | Action |
| --- | --- |
| 1 | File a **formal** request (company form, or written pack with date / type / frequency / reason / start–end) |
| 2 | Diary the **2-month** written-reply clock |
| 3 | If rejected, keep the **written reason** — business grounds vs “we have no FWA policy” smell test |
| 4 | Raise unresolved process concerns through **internal grievance** first (TAFEP employee guide) |
| 5 | Union members → union advice; others → **TAFEP** for Guidelines / employer-engagement help |
| 6 | Salary / wrongful dismissal after complaining → [TADM](/guides/salary-dispute-tadm-mom), not FWA folklore |

## What TAFEP is (and is not) here

| Use TAFEP when | Do not use TAFEP as |
| --- | --- |
| Formal request ignored past two months | A magic “force Bali WFH” button |
| Rejection cites personal bias / no process | Immigration cover for working abroad on EP |
| Employer has no formal FWA channel | A substitute for [workplace harassment](/guides/workplace-harassment-tafep-ep) reporting when the conduct is harassment |
| You need help engaging HR on Guidelines compliance | Legal representation for a lawsuit |

Overseas WFH remains a separate tax / destination-immigration / PE-risk stack — parent guide already flags that. Pass fear after escalating is real; plan [career pivots](/guides/career-pivots-singapore) / [between jobs](/guides/between-jobs-stvp-singapore) as contingency, not as a reason to skip the written record.

## Decision rule

**Formal request → written 2-month reply → internal grievance → TAFEP for process gaps.** Parent filing mechanics stay on [FWA request](/guides/flexible-work-arrangement-request); harassment channels on [TAFEP harassment](/guides/workplace-harassment-tafep-ep).
