**Short answer:** New foreign passport → **FormSG ROE transfer** (one per book) after **name match** — ROE does not auto-migrate and is not ORAL.

r/askSingapore’s “new US passport, old ROE” threads treat the endorsement as permanent ink. ICA’s published rule: when the child gets a **new travel document**, submit a fresh request to **transfer ROE** onto that book. Who ROE is for and the name-match trap live on [Right of Entry under 21](/guides/right-of-entry-roe-under-21-singapore). This companion is the **FormSG / transfer** layer.

## File / transfer sequence

| Step | Detail |
| --- | --- |
| 1. Confirm eligibility | SC **under 21** holding a foreign passport |
| 2. Fix **name match** first if IC / ICA records diverge | IC unit / [name change](/guides/change-name-nric-singapore) before expecting ROE on the foreign book |
| 3. Submit ICA’s **FormSG** ROE request (Singpass) | Separate request for **each** foreign passport if the child holds more than one |
| 4. Wait for ICA confirmation (~**3 working days** when docs are complete) | Fee: **none** |
| 5. On **new** foreign passport → transfer request | ROE does **not** auto-migrate |

Under **16**: parent or parent-appointed proxy files. **16–20**: child may file as requestor.

## What ROE still is not

| Folklore | Reality |
| --- | --- |
| Transfer once, keep dual citizenship forever | No — [ORAL at 21](/guides/oral-dual-citizenship-age-21) still governs retention |
| Confirmation letter = ROE | Different product — [confirmation of citizenship](/guides/confirmation-singapore-citizenship-status) |
| Mission prints ROE like a visa sticker | Follow ICA’s online request / live instructions |
| One ROE covers every foreign passport | FormSG: **separate request per passport** |

## Decision rule

**Name match → FormSG (one per foreign book) → transfer on every passport renewal → diary ORAL separately.** Parent overview stays on [ROE under 21](/guides/right-of-entry-roe-under-21-singapore).
