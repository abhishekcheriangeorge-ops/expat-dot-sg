**Short answer:** On **EP/S Pass assume zero Singapore side income** — paid local brand deals and weekend gigs still count as work for someone else.

Parent overview: [side income & freelancing on work passes](/guides/side-income-freelance-work-pass). This companion is the **creator / weekend-gig** layer Reddit keeps re-litigating as “not a real job.”

## EP / S Pass: designated employer only

MOM’s FAQ does not carve out influencers, photographers, tutors, or Grab. If you are paid for activity **in Singapore** for a Singapore client or brand, treat it as work for someone other than your designated employer — generally **not allowed**.

| Costume | Safer reading on EP/S Pass |
| --- | --- |
| Paid IG / TikTok deal for a Singapore brand | Extra income in Singapore — no |
| “Just one” wedding / corporate shoot | Still a Singapore client gig — no |
| Tutoring locals for cash | Same |
| Weekend Grab / food delivery | Same |
| Unpaid open-source / personal learning | Usually fine until invoices, brand deals, or local customers appear |
| Pte Ltd on the side | Shareholding ≠ moonlighting clearance — [incorporate](/guides/incorporate-company-foreigner-singapore) |

## DP / LTVP: overseas remote is a different FAQ

Dependant’s Pass FAQ: no work pass needed for a clearly **overseas** employer/client with no Singapore-entity linkage and no Singapore clients — while physically in Singapore. Flip any of those and you need the right pass / [business-owner LOC](https://www.mom.gov.sg/passes-and-permits/loc-for-dependants-pass-business-owners/eligibility) **before** you invoice. Tax residency / remittance is still IRAS — [foreign income](/guides/foreign-income-and-tax).

Do **not** copy DP overseas-remote lore onto an EP card.

## Personalised passes are not a freelance licence

PEP generally excludes freelancers / sole props / shareholder-directors. EntrePass is for the venture under published innovator rules — not random gigs. Tech.Pass / ONE Pass multi-activity still sits inside programme text, not tourist side-hustle folklore.

## Decision rule

**Client location + pass type beat invoice labels.** On EP/S Pass assume zero Singapore side income; on DP sort overseas-vs-Singapore before the first invoice; tax is a parallel track.
