**Short answer:** **No finished issuance → no Causeway run.** IPA is not a day-trip stamp; finish medicals, letter, and EPSC before you hop.

Parents: [travel before the card](/guides/travel-before-work-pass-card) · [issuance / EPSC / Notification](/guides/work-pass-issuance-epsc-notification). This companion is the **JB / short hop** failure mode landing-week threads relearn every cycle.

## IPA is not a day-trip stamp

An in-principle approval lets you enter and **finish issuance**. It is not a finished work pass and not a promise you can exit to Johor Bahru and stroll back while HR still owes medicals, issuance fee clearance, Notification Letter, or EPSC biometrics.

| Mid-issuance plan | Risk |
| --- | --- |
| JB lunch on IPA only | Exit may be easy; re-entry can fail while status is incomplete |
| Regional kickoff “for two nights” before Notification Letter | Same — plus airline document checks |
| “Notification Letter is basically the card” | Letter is temporary evidence with a **validity end date** — still confirm ICA/airline path |
| “EPSC next week, trip this weekend” | Biometrics clocks and letter validity collide; finish issuance first |

## HR call script before you book

1. Which MOM steps are still open (medical, issuance fee, Notification Letter, EPSC)?  
2. Do I have written clearance to **leave and return** on my current status?  
3. If I am on STVP / visit conditions, what happens if I exit?  
4. Who is on-call if ICA / airline blocks boarding on return?  
5. Prefer: Notification Letter live + HR OK + SGWorkPass issued view — then travel.

## Decision rule

**No finished issuance → no Causeway run.** Hunger is cheaper than an offshore strand while EPSC slots slip.
