r/askSingapore’s “my company cut my package — does my spouse’s DP die?” threads treat a quiet payroll change as private. MOM does not. Employer notify mechanics (salary, occupation, related-company moves) live on [EP salary & occupation changes](/guides/ep-salary-occupation-changes). This Next companion is the **household DP / LTVP cascade** layer.

## The cut is an immigration event

| Rule | Published orientation (verify live) |
| --- | --- |
| Who notifies | **Employer** (not the pass holder DIY) |
| Timing | Notify **at least 1 month before** the intended lower-salary date |
| Qualifying test | Revised fixed monthly salary must still qualify for the EP — run **SAT** |
| If EP no longer qualifies | Cancel and apply for a pass the person can hold |
| Family cascade | If revised salary fails MOM’s criteria for **DP / LTVP** privileges, MOM **revokes** existing DP/LTVP tied to the work pass |

A handshake pay cut without MOM notify is how families discover revoked dependant passes mid-school term.

## Questions to send HR before you sign the cut

1. Will you file the MOM salary-reduction notify **≥ 1 month** before the effective date?  
2. Please run **SAT** on the revised fixed monthly salary and send screenshots.  
3. Do spouse / child **DP or LTVP** privileges still clear after the cut?  
4. If privileges fail, what is the plan — restore pay, cancel/reapply, or family exit timeline?  
5. Is this a related-company transfer in disguise? (That needs a **new EP**, not a salary notify — [changing jobs](/guides/changing-jobs-employment-pass).)

## Raise vs cut (do not mix the folklore)

| Change | Immediate MOM notify? |
| --- | --- |
| **Salary cut** | **Yes** — employer, ≥1 month before |
| **Raise alone** | Usually **no** — declare at EP renewal |
| **Raise then add dependants** | Notify **before** applying for dependant privileges |
| **Occupation / title rewrite** | Separate employer occupation-update request (~3 weeks) |

Package definitions for “fixed monthly salary” sit on [salary package decoding](/guides/salary-package-decoding). Renewal-year COMPASS firm scores are a different theatre — [EP renewal strategy](/guides/ep-renewal-strategy).

## Decision rule

No written MOM notify + SAT proof + explicit **DP/LTVP still OK** answer → do not treat the cut as safe for the household. Parent notify mechanics stay on [EP salary & occupation changes](/guides/ep-salary-occupation-changes); dependant pass basics on [Dependant’s Pass](/guides/dependant-pass-singapore).
