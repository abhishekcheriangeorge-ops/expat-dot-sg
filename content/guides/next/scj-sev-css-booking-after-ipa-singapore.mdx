**Short answer:** **IPA → wait 3 working days → portal → book SEV/CSS early → finish e-Journey on published clocks.**

r/askSingapore’s post-IPA panic is usually **calendar**, not eligibility: portal login fails on day one, SEV slots look empty, CSS is “once a month.” Stage map and ceremony timing live on [Singapore Citizenship Journey](/guides/singapore-citizenship-journey-scj). This companion is the **day-3 login + booking** layer for ages **16–60** who must finish SCJ.

## Portal clocks that unblock booking

| Clock | Published orientation |
| --- | --- |
| SC Journey Portal login | **3 working days after** IPA letter date (e.g. Friday letter → login from the following Wednesday) — [sgjourney help](http://sgjourney.gov.sg/help) |
| e-Journey particulars / uploads | Up to **7 days** after you start that step (roadmap) |
| Review / submit / pay | Up to another **7 days** |
| SEV + CSS | Book early; inconvenient slot first beats waiting for a mythical empty month |
| IPA letter | **Overrides** Reddit if clocks differ |

Still cannot log in after three working days? Use the portal / ICA contact path named in your IPA pack — not an agent WhatsApp.

## Booking hygiene

1. Diary portal day **+3 working days** the hour IPA lands.  
2. Complete e-Journey inside the **7 + 7** hygiene before sessions expire in your head.  
3. Book **Singapore Experiential Visit (SEV)** and **Community Sharing Session (CSS)** as soon as the portal exposes slots.  
4. Parallel-path foreign-citizenship **renunciation** docs for the ICA Building registration annex if you are **21+** and required.  
5. Model **NS** with [CMPB](https://www.cmpb.gov.sg/) / [citizenship & NS](/guides/citizenship-ns-implications) — SCJ sessions do not waive liability literacy.

Minors already SC by descent/registration face [ORAL at 21](/guides/oral-dual-citizenship-age-21) — not this CSS booking stack.

## Decision rule

**IPA → wait 3 working days → portal → book SEV/CSS early → finish e-Journey on the published clocks.** Parent stage map stays on [SCJ after IPA](/guides/singapore-citizenship-journey-scj); eligibility on [citizenship application](/guides/singapore-citizenship-application).
