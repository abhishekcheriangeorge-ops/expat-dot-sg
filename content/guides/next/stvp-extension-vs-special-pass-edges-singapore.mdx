## STVP buffer ≠ Work Permit Special Pass

After **EP** cancel, MOM’s published path is an employer-requested **Short-Term Visit Pass** (often up to **90 days**) — **stay only**. **Special Pass** language on general FAQs more often tracks **Work Permit / departure** patterns. Mixing the labels is how people miss the form that matches *their* pass.

| Edge | Safer reading |
| --- | --- |
| “HR gave 14-day STVP; ICA will top up” | Ask HR **in writing** for the longest available STVP; ICA tourist rails are a different product — [STVP extension](/guides/short-term-visit-pass-extension) |
| “Special Pass lets me freelancing-bridge” | Cancel ends work rights — STVP/Special Pass stay ≠ work |
| “I’ll fly and return on the same STVP” | Re-entry on STVP is high-risk — treat departure as possibly one-way |
| “Family DP stays while I extend” | Related DPs usually cancel with the principal — same-week plan |

## Extension / travel checklist

1. Get the STVP end date and request channel from HR in email the day cancel is filed.  
2. File any MOM “extend stay” request inside published windows (often ~7–14 days before expiry) — late filings risk overstay.  
3. Do not invent ICA counter extensions for an MOM STVP.  
4. Align tax clearance / exit money with the real last day — [tax clearance](/guides/tax-clearance-when-leaving) · [leaving playbook](/guides/leaving-singapore-playbook).  
5. SC/PR spouse households: STVP is only a short buffer — [spouse LTVP bridge](/guides/ep-job-loss-spouse-ltvp-bridge-singapore).

## Decision rule

**Name the document correctly, ask HR for the longest lawful STVP, and treat travel / extensions as pass-type-specific — not Reddit Special Pass folklore.**
