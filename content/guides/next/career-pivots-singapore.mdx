Your pass is tied to an employer. A pivot usually means a **new sponsorship story**, not just a new LinkedIn headline. Reddit’s blunt version: secure the new IPA **before** you burn the old job — unemployment on a cancelled pass is an exit clock, not a sabbatical.

## Official sequence (EP / S Pass)

MOM’s published position:

1. Ask the **new employer** to submit a **new** EP or S Pass application  
2. You generally **do not** cancel the existing pass before applying  
3. Approval is on merits under prevailing rules (qualifying salary + COMPASS for most EPs; quota/levy for S Pass)  
4. When the new pass is approved, the **old pass is not auto-cancelled** — the current employer cancels after employment ends (typically within **one week**)  
5. Employers cannot weaponise “we won’t cancel” after you lawfully resign; MOM expects cancellation and can assist if they refuse  

Subsidiary / related-company moves usually still need a **fresh application**, not a paperwork transfer.

## Industry switches are harder — for sponsorship reasons

Career changes (design → data, teaching → finance) are possible but companies must justify the hire under current EP/S Pass economics. Locals already find pivots hard; pass sponsorship raises the bar. Quiet market-test while remaining compliant. Do not resign on “verbal EP” promises.

## Practical calendar

| Step | Why |
| --- | --- |
| Quiet search while employed | Pass stays valid |
| Offer clears salary + COMPASS / S Pass gates | Use SAT with new HR |
| New IPA in hand | Only then resign / serve notice |
| Align notice, garden leave, non-compete | IPA expiry and start dates collide |
| Old employer cancels; new pass issued | Family DP/LTVP usually track the main pass |

## Family knock-ons

Dependant and LTVP status typically follows the main pass holder’s employment. Budget for card re-issuance timing, school term disruption, and tenancy diplomatic clauses if the new role fails.
