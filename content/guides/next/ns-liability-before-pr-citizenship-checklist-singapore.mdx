r/askSingapore’s “first-gen PR exemption” threads celebrate IPA before anyone writes **CMPB**. Planning stack lives on [citizenship & NS](/guides/citizenship-ns-implications). This companion is the **pre-PR / pre-citizenship checklist** for households with sons.

## Checklist before you file (or accept) PR / SC

| # | Ask / do | Why |
| --- | --- | --- |
| 1 | List every male child’s **age, citizenship/PR path, and residence country** | Liability hinges on status + age, not passport aesthetics |
| 2 | Read CMPB **overseas pre-enlistee** pages if any son lives abroad | Male SC/PR liability orientation from **13**; register at **16.5**; enlist from **18** |
| 3 | Model **Exit Permit / bond** if overseas stays are **≥3 months** (ages 13+) | Bond orientation: **S$75,000** or **50%** of parents’ combined preceding-year gross income — whichever higher — verify live |
| 4 | Kill “dual citizenship = no NS” folklore | Dual-status males are still NS-liable; Singapore does not recognise dual citizenship for adults |
| 5 | Write **CMPB** for *your* scheme (sponsored child PR vs other paths) | Forum PTS comments are not your letter |
| 6 | Read Exit Permit depth | [NS Exit Permit for PR families](/guides/ns-exit-permit-pr-families) |
| 7 | If anyone is already eyeing renunciation games | ICA may withhold PR renunciation for unresolved NS; MINDEF signalling on later EP/study is historically harsh |

## What this checklist is not

| Folklore | Reality |
| --- | --- |
| “Tourist visits worked, so EP will too after renouncing” | Tourist luck ≠ long-term pass outcome |
| “ORAL at 21 replaces NS modelling” | Different product — [ORAL](/guides/oral-dual-citizenship-age-21) |
| “We’ll decide NS after PR IPA” | IPA celebrations without CMPB clarity are how families get trapped |

## Decision rule

**CMPB letter for your exact boys → then PR/citizenship strategy.** Parent framing stays on [citizenship & NS](/guides/citizenship-ns-implications); stay/exit honesty on [long-term stay vs exit](/guides/long-term-stay-vs-exit).
