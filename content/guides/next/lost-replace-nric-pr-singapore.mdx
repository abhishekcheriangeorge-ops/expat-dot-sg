**Short answer:** Lost **blue PR / pink SC NRIC** → **ICA** Loss of IC e-Service (aim **14 days**), not MOM. Fees are typically **S$100** first loss / **S$300** later (verify live). Digital IC helps daily life but does **not** waive replacement. EP plastic loss is a different rail.

r/askSingapore’s “I lost my IC” threads mix **blue NRIC** (PR / SC) with **FIN work-pass plastic**. They are different agencies, fees, and clocks. If you still hold an EP / S Pass / DP card, use [lost work pass card](/guides/lost-replace-work-pass-card). This guide is for **Identity Cards** — the blue PR card or pink SC card ICA issues after formalities. Name changes and damaged cards use ICA’s **change of particulars** path instead — [change of name on NRIC](/guides/change-name-nric-singapore).

## Immediate moves

1. **Report the loss to ICA** via the Loss of IC e-Service (Singpass) and apply for a replacement — ICA asks you to do this **within 14 days** of the report.  
2. Use **Singpass Digital IC** for day-to-day identity where accepted; do not treat that as a reason to skip the replacement filing.  
3. If the card was **stolen** with a wallet/bag, a **police report** still helps for banks and appeals even though ICA says a police report is **not required** for the IC replacement itself.  
4. If you are **overseas**, report when you can; ICA’s published path is to complete replacement on your **next return to Singapore** via the same e-Service — collection still needs identity authentication in Singapore.

## Fees ICA publishes (verify live)

| Event | Published fee |
| --- | --- |
| First loss | **S$100** |
| Second and subsequent losses | **S$300** |
| Processing | About **7 working days** (longer in peaks); photo / supporting docs can delay |
| Collection window | Book collection within **3 months** of approval — SMS/email notify |

Once a lost-IC replacement application is submitted, ICA issues a **new** IC — no refund if the old card turns up. Reddit “appeal the S$300” stories sometimes work with a strong theft police report and hardship; treat that as discretionary, not policy.

## Lost IC vs re-registration at 30 / 55

Do **not** confuse loss replacement with the compulsory **re-registration** window:

| Situation | Path |
| --- | --- |
| Card missing / stolen / cannot produce | [Loss of IC](https://www.ica.gov.sg/documents/ic/loss) |
| Age **30** (before 31st birthday) or **55** (before 56th), and no replacement IC in the last **10 years** | Deep dive: [NRIC re-registration at 30 / 55](/guides/nric-reregistration-30-55-singapore) — subsidised **S$10** (SC) / **S$50** (PR) after ICA’s digital notification |
| Living overseas during re-registration | Re-register within **one year of return** to Singapore |

Many adult PRs who collected a blue IC in their late twenties never get a “turn 30” notice — ICA’s 10-year rule is the usual reason. Wait for the official SMS / Singpass notification rather than forcing an ineligible re-registration attempt.

## Address stickers and moves

Changing flat or posting overseas is **not** the same as losing the card, but it uses the same identity stack. Full playbook: [eCOA address change](/guides/ecoa-nric-address-change-singapore). IC holders (SC and PR), including those residing overseas, must report a new residential address within **28 days** — PIN mailer to the new address, then sticker on the back of the IC (or a new IC if you are mid-replacement). Forum advice to “put a Malaysian address for REP” is how people torch renewal credibility — see [REP](/guides/re-entry-permit-pr-overseas).

## Work-pass plastic vs blue IC

| | MOM work-pass card | ICA NRIC |
| --- | --- | --- |
| Who | EP / S Pass / DP (and peers) | SC / PR |
| Agency | MOM (employer usually files) | ICA (you file with Singpass) |
| Digital bridge | SGWorkPass | Singpass Digital IC |
| Typical first-loss fee | MOM’s published EP card fees | S$100 |

After PR formalities, your FIN card world ends — update wallets, travel pouches, and the [annual life-admin](/guides/renewing-life-admin-annually) checklist so you are not carrying both plastics “just in case.”

## Decision rule

Report loss fast, replace on ICA’s clock, and keep Digital IC + passport as your travel pair. Paying S$100 once is cheaper than explaining an unreported lost identity document to a bank, club door, or enlistment admin desk.
