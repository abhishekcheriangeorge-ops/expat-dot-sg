**Short answer:** **Assume group cover ends when employment ends → start a personal bridge before cancel → never park elective care in an uninsured STVP week.**

Parent plan audit: [health insurance for expats](/guides/health-insurance-expat). This companion is the **exit / between-jobs bridge** — the uninsured week after group cover ends that Reddit discovers in A&E.

## Group medical usually dies with employment

Most employer schedules end cover on **last day of employment** (sometimes midnight after cancel). STVP stay after EP cancel is **not** medical insurance — [between jobs / STVP](/guides/between-jobs-stvp-singapore). EP/S Pass holders remain outside Medisave / MediShield; public hospitals still bill unsubsidised foreigners unless a scheme says otherwise.

| Window | Typical cover posture |
| --- | --- |
| Employed on EP | Employer group ± personal top-up |
| Notice / garden leave | Often still employed → group may continue — **read the schedule** |
| Day after employment ends / STVP | Usually **no** group cover |
| New employer day one | New group may have waiting periods / underwriting for dependants |

## Bridge checklist (in writing before you resign)

1. Exact **group end date** from HR / broker  
2. Whether dependants drop the same day  
3. Personal **inbound** plan start date + waiting periods (maternity / pre-existing)  
4. Letter of Guarantee (LOG) path if elective care sits near the gap  
5. Cash buffer for deposit-heavy private care — stack with [leaving costs](/guides/leaving-singapore-costs) / IR21 freeze — [IR21 sequencing](/guides/ir21-pass-cancel-stvp-sequencing-singapore)

Work injuries stay on **WICA** rails first — [WICA](/guides/wica-work-injury-compensation-ep) — not “my travel insurance will sort ICU.”

## Decision rule

**Assume group cover ends when employment ends → buy or start a personal bridge before cancel day → never schedule elective care into an uninsured STVP week.** Pass stay and medical cover are different products.
