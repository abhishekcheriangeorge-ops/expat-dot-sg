**Short answer:** **Renew ICA LTVP first (≥3 months out)** → then tick PLOC / FormSG ad-hoc or let the employer renew LOC — PLOC dies with the LTVP.

r/askSingapore’s “my PLOC expires next month” threads try to renew the work letter while the **LTVP card is already thin**. Product chooser (PLOC vs employer LOC vs graduate myths) lives on [PLOC vs LOC](/guides/ploc-loc-ica-ltvp-singapore). This companion is the **renewal sequencing** layer.

## PLOC — LTVP first, always

| Rule MOM publishes | Operating move |
| --- | --- |
| PLOC validity is **tied to** the current ICA LTVP / LTVP+ | A short residual LTVP makes a thin PLOC |
| LTVP expiring soon | **Renew LTVP with ICA first** (≥3 months before expiry orientation) |
| Want PLOC on renewal | Tick PLOC when renewing LTVP / LTVP+ if still eligible |
| Skipped PLOC on renewal | Ad-hoc request **2 days after** receiving the renewed LTVP card — FormSG, **holder’s own Singpass** (not employer / EA) |
| Stop working | You do **not** need to “cancel” PLOC — simply skip it on the next LTVP renewal |

Outcome email usually within about a **week** (check junk). Each PLOC is assessed on merits — renewal is not a rubber stamp.

## Employer LOC — different renew rail

| Topic | Published orientation |
| --- | --- |
| Who renews | **Employer** or appointed EA via EP eService |
| When | Up to **6 months** before LOC expiry |
| Prerequisite | LTVP / LTVP+ valid for at least **3 months** — else renew ICA LTVP first |
| Cost / clock | Free · about **1 week** (some longer) |
| Cancel | Within **1 week** after last day of notice (advance cancel up to 14 days) |

Restricted occupations and PLOC refusals still use this LOC path — parent guide. Lost LOC → employer reports loss / replaces.

## Decision rule

**Diary ICA LTVP ≥3 months out → renew stay → then PLOC (tick or FormSG) or employer LOC renew.** Parent chooser stays on [PLOC vs LOC](/guides/ploc-loc-ica-ltvp-singapore); spouse stay product on [spouse LTVP + PMLA](/guides/spouse-ltvp-pmla-singapore).
