## Calendar math beats shareholding folklore

Renewal commonly wants a Singaporean/PR hire at/above live **Local Qualifying Salary** plus **three consecutive months** of CPF **before** you submit. ACRA shareholding that cleared year one does not compress that CPF calendar.

| Timing folklore | Safer reading |
| --- | --- |
| “Hire the week before renewal” | Three CPF months need ~90+ days of real payroll — start early |
| “Intern / part-time counts if CPF shows” | Check live LQS + employment shape — screenshots ≠ eligibility |
| “Spouse on CPF fixes it” | Related-party / genuine-employment facts still matter — verify live |
| “First LOC letter renews itself” | First approval ≠ renewal evidence pack |

## Hire-timing checklist

1. Count backward **three CPF months + buffer** from the LOC expiry / filing target.  
2. Keep LQS and CPF contribution records with the ACRA extract.  
3. If the hire will miss, pause Singapore-client work and pick [own EP](/guides/employment-pass-singapore) / overseas-only clients — [side income](/guides/side-income-freelance-work-pass).  
4. Sequence principal [Dependant’s Pass](/guides/dependant-pass-singapore) renewal before LOC — LOC dies with the DP.  
5. Trailing-partner framing: [trailing partner career](/guides/trailing-partner-career-singapore).

## Decision rule

**Start the LQS hire early enough for three CPF months — last-week hiring does not rewrite MOM’s renewal calendar.**
