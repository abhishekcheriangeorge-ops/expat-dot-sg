r/askSingapore’s “I got laid off but my spouse is Singaporean — do I still only get 30 days?” threads mash **STVP**, **Dependant’s Pass**, **spouse LTVP**, and **graduate LTVP** into one panic. They are different products. This guide is the bridge when the **main EP dies** and a **Singapore citizen or PR spouse** can sponsor ICA **spouse LTVP**.

Generic between-jobs choreography (ask HR for up to **90-day** STVP, DP cascade, IR21) stays on [between jobs on EP](/guides/between-jobs-stvp-singapore). Spouse LTVP mechanics / PMLA depth live on [spouse LTVP + PMLA](/guides/spouse-ltvp-pmla-singapore).

## Product chooser after EP cancel

| Goal | Likely product |
| --- | --- |
| Short buffer to pack / interview while still in SG | Employer-requested **STVP** on EP cancel — MOM publishes **up to 90 days**; default HR behaviour is often shorter unless someone asks |
| Longer stay as foreign spouse of **SC / PR** | ICA **spouse LTVP** sponsored by the local spouse |
| Work while on that LTVP | **PLOC** or employer **LOC** — [PLOC / LOC](/guides/ploc-loc-ica-ltvp-singapore) |
| Stay-to-hunt as a local IHL graduate **without** SC/PR spouse sponsorship | [Graduate LTVP](/guides/graduate-ltvp-job-hunt) — different eligibility row |
| Permanent status | [Spouse-sponsored PR](/guides/pr-for-spouse-singapore) — not automatic when EP dies |

Dependant Passes tied to the EP usually **fall with** the main pass — do not assume the trailing spouse’s DP survives the cancel. Full DP mechanics: [Dependant’s Pass](/guides/dependant-pass-singapore).

## Sequencing that actually works

1. **Before cancel day** — confirm with HR in writing: cancellation date, whether they will request the **longest STVP MOM allows**, and IR21 / final-pay withholding ([tax clearance](/guides/tax-clearance-when-leaving)).  
2. **If you are already married to an SC** — spouse LTVP can run in parallel with notice / STVP; PMLA only helps if you completed it **before** marriage (it is not a post-layoff hack).  
3. **If you are married to a PR** — no PMLA path; file spouse LTVP on the published PR-sponsor clock (~6 weeks orientation when docs are in order).  
4. **If you are not yet married** — ROM + LTVP is a multi-week project; STVP length and leave-to-exit planning matter more than WhatsApp “just marry next week” folklore. Work Permit holders still need MOM marriage approval where published.  
5. **Work rights** — LTVP alone is stay. Tick **PLOC** with the LTVP file (or request later) / use employer LOC for restricted occupations.  
6. **Lease / school / helper** — STVP is a bridge, not a housing plan; if the household is exiting instead, switch to [leaving playbook](/guides/leaving-singapore-playbook).

Peers sometimes apply for spouse LTVP **while still on EP** (with a termination letter / explanation). Treat that as **case-by-case ICA practice**, not a published “must wait until STVP” rule — your IPA / LTVP outcome letter still wins.

## Money and work myths to kill

| Myth | Safer reading |
| --- | --- |
| “STVP lets me keep working until day 90” | STVP is **visit** stay after cancel — not EP work rights |
| “PLOC is automatic with spouse LTVP” | Optional / assessed — ask for it; see [PLOC guide](/guides/ploc-loc-ica-ltvp-singapore) |
| “Graduate LTVP is the same as spouse LTVP” | Different ICA rows; graduate stay-to-hunt is **not** a PLOC spouse product |
| “EP cancel auto-starts spouse PR” | PR remains discretionary — [spouse PR](/guides/pr-for-spouse-singapore) |

Retrenchment **money** (notice, TADM) is separate: [retrenchment on EP](/guides/retrenchment-ep-benefits).

## Decision rule

On notice of EP loss, run **two clocks**: HR’s STVP request (push for up to 90 days) and, if your spouse is SC/PR, the **spouse LTVP** file with PLOC if you need lawful work. Do not wait for a 30-day default to expire before the local spouse opens ICA e-Service — and do not confuse a visit pass buffer with a career plan.
