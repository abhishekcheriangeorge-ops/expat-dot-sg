r/askSingapore’s “my spouse died on EP — do the kids’ DPs still work?” threads mash **funeral admin**, **pass cancellation**, and **Special Pass folklore** into one panic. Certificates and NEA permits live on [death & repatriation](/guides/death-repatriation-foreigners-singapore). This page is the **pass cascade** companion when the **main Employment Pass (or S Pass) holder dies** and Dependant’s Passes ride on that sponsorship.

This is orientation for next of kin — not immigration advice for a specific file. Employer HR / MOM eService / ICA win over WhatsApp.

## What MOM publishes on DP cancel

MOM’s cancel page is blunt about family passes tied to a work pass:

| Situation | Published posture |
| --- | --- |
| You cancel the **main work pass** | **DPs for family members are cancelled at the same time** |
| DP no longer needed (other reasons) | Cancel via EP eService (up to 14 days in advance) |
| DP already expired but holder still in Singapore | Request a **Short-Term Visit Pass (STVP)** for valid stay |
| DP holder still in Singapore after cancel | Request STVP — MOM states it can grant valid stay for **up to 90 days** from the application date |

Death of the main pass holder is an employer / next-of-kin cancel path, not a “DP keeps running until the card date” loophole. Plastic validity dates on cancelled DPs do not keep immigration status alive.

[MOM — Cancel a Dependant’s Pass](https://www.mom.gov.sg/passes-and-permits/dependants-pass/cancel-a-pass). Pass overview: [Dependant’s Pass](https://www.mom.gov.sg/passes-and-permits/dependants-pass).

## Sequence that actually matters in the first week

1. **Death certification + digital certificate** — start [death & repatriation](/guides/death-repatriation-foreigners-singapore) the same day as HR.  
2. **Notify the employer / agent** in writing that the main pass holder has died and that DPs must be cancelled / STVP requested for survivors still in Singapore.  
3. **Do not assume LOC / Letter of Consent work rights survive** — MOM notes related LOC / Work Permit cancel with the DP.  
4. **Collect STVP emails** — MOM says both the cancel requester and the DP holder receive the STVP by email; survivors need it (plus passport) when leaving.  
5. **Schools / lease / helper** — treat STVP as a **bridge**, not a housing or enrolment plan. If the household is exiting, switch to [leaving playbook](/guides/leaving-singapore-playbook) and [tax clearance](/guides/tax-clearance-when-leaving) clocks for the estate / final pay.  
6. **Banks / probate** — pass cancel does not unfreeze accounts; that is still [wills & probate](/guides/wills-probate-cpf-nomination-singapore).

## Special Pass vs STVP vs “just stay on the DP card”

| Folklore | Safer reading |
| --- | --- |
| “DP card date is still in the future, so we’re fine” | Cancel follows the **main pass**; card plastic is not the status |
| “ICA Special Pass automatically replaces DP for widows” | ICA Special Pass / e-Special Pass is issued for **specific purposes** (investigation, court, etc.) — not a published widow entitlement. Contact ICA only if they direct you there; do not invent a purpose |
| “This is the same as layoff STVP” | Job-loss STVP choreography is [between jobs on EP](/guides/between-jobs-stvp-singapore). Death cancel is a different trigger with the same **up-to-90-day** STVP tool on MOM’s cancel page |
| “Kids can keep school on an expired DP” | Schools need lawful stay proof — STVP / new pass / exit plan, not a cancelled FIN card |

<OfficialSource>
ICA’s public explainer: [Special Pass card / e-Special Pass](https://www.ica.gov.sg/public-education/special-pass) — purpose-limited; overstaying after expiry is an offence.
</OfficialSource>

## Decision rule

On the day of death, run **two projects in parallel**: NEA / embassy / certificate admin, and **employer cancel of the main pass + DPs with STVP for anyone still on the ground**. Do not wait for the funeral to finish before asking HR for the MOM cancel / STVP path — and do not confuse a visit-pass bridge with a long-term stay plan. Probate and CPF nomination stay on their own rails.
