## LOC is a second product, not a vibe

ONE Pass reopened a real **Letter of Consent** path for spouses that ordinary EP Dependant’s Pass households largely lost after 2021. It is still **not** automatic work rights. Sequence matters: principal ONE Pass → eligible family pass → LOC.

| Folklore | Safer reading |
| --- | --- |
| “Spouse can work the day ONE Pass issues” | Legally married spouse usually needs a **Dependant’s Pass first**, then LOC |
| “Two LOCs — job plus side company” | MOM’s FAQ: **one LOC at a time**; own company counts as the employer |
| “Common-law partner is the same as married spouse” | Common-law path is typically **LTVP + published LOC route** — still not automatic |
| “Our friends on EP DP can copy this” | Ordinary EP/S Pass DP work LOC folklore is the wrong playbook — [Dependant’s Pass](/guides/dependant-pass-singapore) |

## Sequencing checklist for dual-career households

1. Confirm the principal actually clears ONE Pass salary / company / outstanding-achievements tests — [chooser](/guides/pep-one-tech-pass-chooser-singapore).  
2. Issue / renew the spouse **DP** (or applicable LTVP for common-law) with enough validity before LOC filing (commonly discussed as ≥**3 months** card validity — **verify live**).  
3. Decide **employment LOC** vs **business-as-employer LOC** — you cannot stack both.  
4. If the “spouse plan” is overseas remote only, read [side income / freelance](/guides/side-income-freelance-work-pass) instead of forcing an LOC story.  
5. Do not resign the trailing partner on “ONE Pass IPA submitted” vibes — wait for the LOC outcome that matches the job offer.

## Decision rule

**Treat spouse LOC as a separate filing with its own eligibility and one-employer limit — never as a free add-on that ordinary EP households can copy.**
