r/askSingapore’s “lost my EP card in Bangkok, can I still fly home?” threads mix **airline check-in**, **SGWorkPass**, and **MOM re-entry letters**. Fees, 1-week replacement, and in-Singapore playbooks live on [lost / damaged work pass card](/guides/lost-replace-work-pass-card). This companion is the **overseas loss / re-entry** layer.

Pass status sits against your **passport** with MOM — the plastic is not the only proof — but replacement is still mandatory, and desks abroad often want something printable.

## Same-day overseas sequence

| Step | Who | Why |
| --- | --- | --- |
| 1. Open **SGWorkPass** / Singpass digital work pass | You | Counter proof of validity |
| 2. Message **HR** the same day (photo of police report if stolen) | You → HR | Only employer / EA can file most replacements in EP eService |
| 3. File local **police report** if stolen | You | MOM replacement hygiene |
| 4. Ask HR to **inform MOM immediately** and request a **re-entry letter** if you must fly before a new card exists | HR → MOM | Overseas-loss path on MOM’s replace-card guidance |
| 5. Still complete **physical card replacement within 1 week** of loss | HR | Digital pass does **not** waive the plastic clock |

## What usually fails at the airport

| Failure mode | Fix |
| --- | --- |
| Airline desk wants “visa / FIN card” | Show SGWorkPass + passport; have HR WhatsApp on standby |
| Card lost + **passport also renewed** overseas | Update travel-document particulars in EP eService — broken passport link is a separate trap |
| Assuming digital pass skips replacement | It does not — 1-week employer filing clock still runs |
| Blue **PR NRIC** lost abroad | Wrong agency — [lost NRIC](/guides/lost-replace-nric-pr-singapore) is ICA, not MOM |

## Fee orientation (EP card page — verify live)

| Case | Published band |
| --- | --- |
| Damaged card | About **S$65.40** incl. GST |
| First lost / stolen | About **S$109** |
| Subsequent losses | About **S$327** |
| Collection | Often ~**4 working days** after approval at EPSC |

Repeated losses can trigger a MOM interview. If the old card turns up later, return it as MOM instructs.

## Decision rule

Overseas loss → **HR same day** → SGWorkPass for the flight → MOM **re-entry letter** if plastic will not exist before boarding → still finish card replacement inside **1 week**. In-Singapore fee table and prevention checklist stay on [lost / replace work pass card](/guides/lost-replace-work-pass-card).
