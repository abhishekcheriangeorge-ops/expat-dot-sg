**Short answer:** SC renunciation: assemble the pack **before** the no-save portal, optionally hold up to **3 months**, mail **originals**, and treat **S$35** as spent — withdrawal after processing fails.

r/askSingapore’s “I paid S$35 then changed my mind” and “ICA says originals not received” threads sit **after** the eligibility decision. Who can renounce, NS gates, and ORAL vs renunciation live on [renouncing Singapore citizenship](/guides/renouncing-singapore-citizenship). This companion is the **portal / cooling-off / originals** layer.

## What you upload vs what you must post back

ICA splits the pack into **digital uploads** and **originals that must physically reach ICA** before processing starts:

| Layer | What ICA lists |
| --- | --- |
| Certified true copies to **upload** | Foreign citizenship certificate; valid foreign passport if obtained; deed poll / name-change / marriage docs if the name changed |
| Mandatory forms to **upload** (then return originals) | Notarised **Statutory Declaration of Renunciation**; **Advisory Note on Renunciation Implication**; **MINDEF Advisory Note** (males) |
| Originals to **return** | Singapore **IC**; valid Singapore **passport**; Singapore **Citizenship Certificate** where applicable — plus the **original** mandatory forms above |

No-save portal: ICA’s user guide says the online form takes ~30 minutes and has **no save** — assemble certified copies and notarised forms **before** you click start.

## Cooling-off — optional hold, hard edges

ICA lets you select a **cooling-off period of up to 3 months** so processing does **not** start immediately:

| Rule ICA publishes | Practical reading |
| --- | --- |
| Hold up to **3 months** | Application sits; processing clock starts after the hold (and after originals arrive) |
| **No extension** of cooling-off | Pick the hold once; do not plan a second extension |
| Withdraw **before** processing | Possible during cooling-off / before process — **fee generally not refunded** |
| Withdraw **after** processing | ICA: withdrawal request **will not succeed** if renunciation is already processed |

Cooling-off is a rethink buffer, not a “park my passport forever” tool. If foreign naturalisation proof is still shaky, fix that **before** you pay — ask.gov.sg still requires documents showing you **are or are about to become** a citizen elsewhere.

## Fee and processing clocks

| Admin fact | Published detail |
| --- | --- |
| Fee | **S$35** collected online at application (card / PayNow) |
| General processing | About **3 months** from receipt of **all** required documents |
| With cooling-off | Processing time is **longer** by the hold you selected |
| Proof of postage | ICA may ask for tracking / delivery status for originals you mailed |

Overseas applicants use the same portal; missions can notarise and may accept originals for onward transmission — still budget courier / travel time into the three-month orientation.

## Myths this companion kills

| Folklore | Published reading |
| --- | --- |
| “Upload PDFs only — originals are optional” | Processing waits on **originals received** |
| “Cooling-off is automatic 3 months” | You **select** it; default is not a free hold |
| “I can get the S$35 back if I withdraw” | ICA: generally **no refund** on withdrawal |
| “This is the same as renouncing PR” | Different product — [renouncing PR](/guides/renouncing-pr-singapore) |
| “Missed ORAL = same paperwork” | Automatic SC loss at 22 ≠ registered renunciation — [ORAL](/guides/oral-dual-citizenship-age-21) |

## Decision rule

Notarise and assemble the full pack **before** opening the no-save form; decide cooling-off with a calendar (foreign citizenship proof + travel for originals); mail or hand in originals with tracking; treat S$35 as spent once paid. Eligibility and NS withholding still sit on [renouncing Singapore citizenship](/guides/renouncing-singapore-citizenship) — this page only keeps the admin from becoming the failure mode.
