r/askSingapore’s “do I re-register at 30 if I replaced my IC last year?” threads mix **compulsory age windows**, **loss replacements**, and **overseas collection folklore**. ICA’s rule is narrower than the group chat. Overseas / return clocks: [NRIC re-registration overseas return](/guides/nric-reregistration-overseas-return-singapore).

## Who must re-register

The Identity Card is a **compulsory** document SC and PR holders must re-register when they reach:

| Window | Deadline language ICA publishes |
| --- | --- |
| Age **30** | Before the **31st** birthday |
| Age **55** | Before the **56th** birthday |

**Carve-out:** if you were issued a **replacement IC within the last 10 years**, that age window does **not** force another card. A mid-twenties loss replacement can skip the “turn 30” ritual — which is why many PRs never see a birthday SMS.

Do **not** confuse this path with [lost / stolen IC](/guides/lost-replace-nric-pr-singapore) (different fees) or [name / particulars change](/guides/change-name-nric-singapore) (S$60 change-of-particulars).

## Notification → file → collect

1. **Wait for ICA’s digital notice** (SMS / Singpass app). Eligible people get a subsidised window of **one year from the notice date** to file online.  
2. Log in to ICA’s e-Service with **Singpass**, upload a passport-sized **digital colour photo taken within the last three months**, and any name / marriage docs the form asks for.  
3. Pay the subsidised fee ICA publishes: **S$10** (citizen) / **S$50** (PR).  
4. Processing: about **seven working days** (longer in peaks). Bad photos or weak supporting docs delay the file.  
5. On approval (SMS + email), book collection **within three months**. Collection needs identity authentication **in Singapore** — embassies do not hand over NRICs.

### Documents ICA lists (high level)

| Holder | Typical digital uploads |
| --- | --- |
| **Citizen** | Optional religious-name / deed-poll / marriage docs if you are changing particulars; recent photo |
| **PR** | Current foreign **passport bio page** (new name on passport first if renaming); marriage cert if adding married name; recent photo |

PRs renaming mid-re-registration still follow the passport-first rule — same trap as [name change](/guides/change-name-nric-singapore).

## Overseas during the window

If you live abroad when the re-registration period hits, ICA requires you to re-register **within one year of returning to Singapore**. Forum hopes of “collect at the consulate” collide with ICA’s published need for fingerprints / facial matching in Singapore — plan the trip around collection, not the other way around. Deep dive: [overseas return clocks](/guides/nric-reregistration-overseas-return-singapore). REP discipline while overseas stays on [REP](/guides/re-entry-permit-pr-overseas).

## Address change mid-application

If your re-registration (or any IC replacement) lists a **new** residential address, ICA still sends the **6-digit PIN** mailer to that address and will not finish the IC file until you verify the PIN on the e-Service. You then get a **new IC with the new address printed**, not just a sticker — see [eCOA / address change](/guides/ecoa-nric-address-change-singapore).

## Decision rule

Diary **30** and **55**, but only file after ICA’s notice (or after you confirm you are inside the 10-year carve-out). Use the subsidised fee path, treat photo rejects as the common delay, and book a Singapore collection slot inside three months — do not laminate a cracked card hoping age 55 will save you if loss fees already apply.
