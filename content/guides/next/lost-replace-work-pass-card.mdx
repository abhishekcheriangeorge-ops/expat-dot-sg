**Short answer:** Tell **HR the same day**, open **SGWorkPass**, and get a **MOM card replacement within 1 week** (police report first if stolen). Digital pass helps at counters — it does **not** waive the plastic replacement. Blue PR NRIC loss is an **ICA** path, not MOM.

Losing a wallet on a JB weekend is a classic r/askSingapore thread. Your **pass status** lives with MOM/ICA against your passport — the plastic card is not the only proof — but you still must replace a lost, stolen, or damaged card on MOM’s timeline.

**Wrong agency check:** if you already hold a **blue PR NRIC** (or pink SC card), ICA runs that replacement — not MOM. See [lost / stolen NRIC](/guides/lost-replace-nric-pr-singapore).

## Immediate moves

1. **Set up / open SGWorkPass** and show the digital work pass if a counter needs validity proof.  
2. Message **HR / employer** the same day — only they (or an appointed EA) can submit most card replacements in EP eService.  
3. If **stolen**, file a **police report** before replacement.  
4. If lost **overseas**, get HR to inform MOM immediately; MOM can issue a letter so you can re-enter Singapore.

## Replacement rules (EP example — verify live)

| Item | MOM position (EP card page) |
| --- | --- |
| Deadline | Employer must apply within **1 week** of loss / damage / theft |
| Who applies | Employer or appointed employment agent |
| Damaged card fee | S$65.40 (incl. GST; non-refundable) |
| First lost / stolen | S$109 |
| Subsequent losses | S$327 |
| Approval | Often immediate; collect at EPSC ~**4 working days** after approval |
| Digital pass | Free; set up immediately — does **not** waive physical-card replacement |

Repeated losses can trigger an interview. If a lost card turns up later, return it to MOM by post as instructed.

## Travel without the plastic

Forum consensus that matches MOM’s digital-pass push:

- Immigration gantries usually read your **passport-linked** status — many people re-enter without showing the card.  
- The hard part is often the **airline check-in** desk wanting proof you can enter Singapore — have SGWorkPass / Singpass ready, plus HR contact.  
- Changing passports without updating MOM/ICA breaks the link — update travel-document details in EP eService when you renew a passport.  
- Lost the card **overseas** and need a MOM re-entry letter before the flight — [lost work pass overseas / re-entry letter](/guides/lost-work-pass-overseas-reentry-letter).

## Who replaces what

| Pass type | Typical path |
| --- | --- |
| EP / S Pass + dependants on employer | Employer via EP eService |
| PEP / ONE Pass / EntrePass family without a current employer path | EA appointment or EPSC appointment flows — follow MOM’s “replace a pass card” notes for your pass |
| 3+ losses blocked online | “Lost card interview” appointment path on MOM’s appointment service |

## Prevention checklist

- Install SGWorkPass on day one — see also [apps that matter](/guides/apps-that-matter-singapore).  
- Keep a photo of the card front/back in a password vault (not in a public chat).  
- Do not laminate or punch holes in the card.  
- Add “pass card in travel pouch” to your [annual life-admin](/guides/renewing-life-admin-annually) review.

After PR formalities, stop treating the old FIN card as your identity — update wallets and travel pouches when you collect the blue IC ([after PR checklist](/guides/after-getting-pr-checklist)).

Plastic is replaceable. Ignoring the one-week replacement clock is not.
