r/askSingapore’s “foreign uni wants a stamped citizenship certificate” threads buy the wrong product twice. ICA’s published answer is a **digital Confirmation of Singapore Citizenship Status** letter — **S$20**, about **3 working days**, **no** signatures / stamps / QR. Product overview lives on [confirmation of citizenship](/guides/confirmation-singapore-citizenship-status). This companion is the **foreign-authority / FormSG** layer.

## How to file (post–March 2024)

| Step | Detail |
| --- | --- |
| Channel | Online FormSG — missions redirect to [go.gov.sg/confirmationofsc](https://go.gov.sg/confirmationofsc); hardcopy at ICA / missions is **no longer** the path |
| Fee | **S$20** (card / PayNow), non-refundable |
| Processing | About **3 working days** when docs are complete |
| Output | Digital letter stating current status (SC or not SC) — ICA says no stamp / QR |

Eligibility remains broad: current or former NRIC/FIN holder, or Singapore birth certificate holder. The letter reports status; it does **not** rewrite [ORAL](/guides/oral-dual-citizenship-age-21) or reopen [renunciation](/guides/renouncing-singapore-citizenship).

## When the foreign desk rejects the PDF

1. Ask the school / mission **in writing** what format they accept (wet-ink, apostille chain, embassy attestation).  
2. Do **not** assume ICA will reprint a stamped version of this letter — published product is digital-only.  
3. If they need attested copies of **other** documents (birth cert, IC scan), that is the [apostille / notary](/guides/document-apostille-notary-singapore) stack — different from this S$20 status letter.  
4. Under-21 checkpoint clearance on a **foreign** passport is [ROE](/guides/right-of-entry-roe-under-21-singapore), not this letter.

## Proxy traps

- Under **16** → parent or parent-appointed proxy as requestor.  
- **16+** → can request as themselves.  
- Appointed proxy → authorisation letter + requestor’s Singapore IC.

Incomplete uploads burn the three-day clock — follow the live FormSG document list.

## Decision rule

**Confirm the foreign authority’s format first → pay S$20 once for ICA’s digital letter → escalate to apostille/notary only for other docs they name.** Parent overview stays on [confirmation of citizenship](/guides/confirmation-singapore-citizenship-status).
