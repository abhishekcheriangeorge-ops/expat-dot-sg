r/askSingapore’s post–1 Dec 2025 threads mash **expired REP**, **visit pass**, **“reinstatement”**, and **PRSEP** into one panic. The orientation guide is [Re-Entry Permit overseas](/guides/re-entry-permit-pr-overseas). This page is the **FAQ companion**: published scenario answers from ICA’s revision FAQ and MHA’s notice — not a second renewal how-to.

## When the 180-day clock starts

From **1 December 2025**, if you are **physically outside Singapore without a valid REP**, you have **180 days** to **apply** for an REP before PR is lost. ICA’s FAQ splits the start date:

| Situation | Clock starts |
| --- | --- |
| You **left without** a valid REP | Date of **departure** |
| You left with a valid REP that **expired overseas** | Date of **REP expiry** |
| You were already overseas without a valid REP **on 1 Dec 2025** | **1 December 2025** (MHA’s transition rule) |

Meeting the deadline means you **filed** inside 180 days. It does **not** mean ICA must approve.

## Myths the FAQ kills

| Folklore | ICA / MHA published reading |
| --- | --- |
| “I’m in Singapore with an expired REP — I’ve already lost PR” | **No.** If you are **in Singapore**, an expiring / expired REP does not itself cancel PR. Renew **before you leave**. |
| “I can fly out on a nearly-expired REP if I return before the date” | You **retain** PR if you return **before** expiry — still renew before the next trip. |
| “I came back within 180 days, so I’m fine even if I never applied” | **Wrong.** Returning mid-window does **not** stop the clock. Fail to apply inside 180 days → PR lost the **day after** the window ends — **even if you are already back**. |
| “PRSEP is a new multi-year REP” | **No.** PRSEP is a **single-entry** checkpoint pass for re-entry during the window. Your **Entry Permit** still governs stay. |
| “I entered on PRSEP, so I can ignore the REP application” | ICA’s FAQ: apply for a new REP inside the 180 days **even after** returning on PRSEP. |
| “Missed the window / got refused — I’ll appeal reinstatement” | MHA / ICA: **no reinstatement** once PR is lost under this process. Only a **fresh PR application** if eligible. |

## What PRSEP actually is

During the 180-day prescribed period you remain a PR. Subject to checkpoint assessment and public-health rules, ICA may issue a **Permanent Resident’s Single-Entry Pass (PRSEP)** so you can re-enter **without** a valid REP.

ICA’s FAQ is specific:

- Valid for **one** entry on the **date stated** on the pass  
- It does **not** carry a separate multi-day “visit validity” the way tourist folklore imagines — stay is tied to your **Entry Permit** while you are still a PR  
- It is **not** a substitute for renewing or obtaining a proper REP before the next departure  

If your in-window REP application is **refused** after you entered on PRSEP, PR is lost the **day after** the outcome is sent; ICA says you are then issued a **Visit Pass**.

Do not plan a career / school year around PRSEP. Treat it as an emergency re-entry bridge while you regularise.

## Outcomes after you apply (or don’t)

| Path | Published outcome |
| --- | --- |
| Applied inside 180 days → **approved** | You remain PR, subject to Entry Permit / REP conditions |
| Applied inside 180 days → still pending | You generally **remain PR until the outcome** |
| Applied inside 180 days → **refused** | PR lost the **day after** the outcome is sent (even if you are in Singapore) |
| Never applied inside 180 days | PR lost the **day after** the period ends (overseas **or** already returned) |
| Lost PR under this process | **No appeal for reinstatement** — fresh PR application only |

ICA also states you will receive **notification** when PR is lost. Diary the window yourself; do not wait for a friendly reminder.

## Decision rule

Renew or obtain a normal REP **before** you leave whenever you can. If you are already overseas without a valid REP, **count 180 days from the published start date**, file inside that window, and treat PRSEP as a **one-shot re-entry** tool — not a travel plan. After loss, model [fresh PR strategy](/guides/pr-application-strategy) / [rejection & reapply](/guides/pr-rejection-reapply), or a deliberate [renunciation](/guides/renouncing-pr-singapore) if you are exiting on purpose. Passport number changes still need [Transfer REP](/guides/transfer-rep-new-passport) on a **valid** REP — transfer is not a 180-day rescue.
