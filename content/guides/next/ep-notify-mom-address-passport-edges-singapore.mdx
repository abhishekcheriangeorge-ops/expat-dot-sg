Parent map: [Notify MOM of EP changes](/guides/ep-notify-mom-address-passport). This companion is the **edge** depth — where the five-day address/mobile clock, FWTES landlord lag, and passport auto-gate window collide with travel or household moves.

## One clock ≠ one trip

MOM wants residential address or mobile updated within **5 days**. Passport particulars update in EP eService, then automated gates typically need about **4 working days**. Doing a same-week move, passport renewal overseas, and a long-haul flight is how people invent “MOM should just know.”

| Edge | Safer reading |
| --- | --- |
| Renew passport overseas, fly home next day | Update eService immediately; expect manual lanes until the auto-gate window clears |
| Move into a condo while landlord stalls FWTES | Five-day clock still runs on **you** — escalate owner consent early |
| DP / family address “should sync” | Do not assume dependant files inherit EP address updates — check each pass rail |
| Hotel / Airbnb as temporary EP address | Often refused — use a declare-able stay ([serviced apartment](/guides/first-housing-serviced-apartment)) |

## Edge checklist

1. Sequence **address** and **passport** updates before the flight that needs automated gates.  
2. Print / save EP eService acknowledgements — banks and landlords still ask.  
3. If FWTES blocks the address, keep written landlord escalation while you remain inside the five-day story.  
4. Card lost/stolen is a different rail — [lost / replace work pass card](/guides/lost-replace-work-pass-card).  
5. Keep bank KYC addresses consistent with MOM — [banking](/guides/opening-bank-account-expat) · [relocation checklist](/guides/relocation-checklist-7-30-90).

## Decision rule

**Update address/mobile inside five days and passport before you need auto-gates — travel, landlord lag, and family sync are not exemptions from EP eService.**
