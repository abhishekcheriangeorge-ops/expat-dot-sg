**Short answer:** Rejected PR → **appeal e-Service only** for fixable same-file gaps; **fresh reapply** when life truly changed — never a second concurrent file.

r/askSingapore’s post-refusal threads mix three different moves: **appeal**, **update a pending file**, and **fresh reapply**. Pending updates and the high-level refusal map live on [PR rejected: appeal & reapply](/guides/pr-rejection-reapply). This companion is the **appeal evidence vs refile** chooser.

ICA does **not** publish your individual refusal reasons. Treat “I know what they dinged” forum archaeology as fiction.

## Three doors — pick one

| Situation | Correct door |
| --- | --- |
| Application still **pending** | Wait / upload material updates inside the live file — **not** the appeal e-Service |
| Application **rejected** and you want the same filing reviewed with extra context | **Appeal e-Service** |
| Rejection stands / appeal failed / life actually changed | **Fresh PR application** when circumstances changed |

Do **not** open a second concurrent PR file while one is pending or under appeal.

## Appeal e-Service rules peers skip

| Rule ICA publishes | Detail |
| --- | --- |
| Channel | Dedicated **appeal e-Service** only |
| Not accepted | In person, email, or post (per ICA’s appeal page) |
| Who files | Original **sponsor** with Singpass; if no sponsor, the **main applicant** |
| Non-Singpass originals | Use the **same email** as the first filing |
| Outcome | Email + online status; timelines vary |

## What belongs on appeal vs refile

| Evidence type | Better on **appeal** | Better on **fresh reapply** |
| --- | --- | --- |
| Documents missing / corrupted on the first file | Yes — supply the corrected pack | Only if appeal window missed |
| Clarifying letter on existing facts (job scope, family timeline) | Sometimes | If appeal closed |
| **New** sustained salary band / new employer | Rarely “same file” | Yes — material change |
| Marriage length / new child / local schooling years that did not exist before | Weak if nothing new | Yes when the change is real |
| Identical PDF pack six weeks later | No | No — wastes the non-refundable fee |

ask.gov.sg’s ICA framing: after an unsuccessful outcome, **consider a fresh online application when circumstances change**. Community “hard six-month cooldown” lore is not a substitute for your rejection letter / live ICA pages.

## Decision rule

Pending → update the live file. Rejected with fixable document gaps → appeal e-Service. Rejected with a genuinely stronger life profile → fresh reapply.
