**Short answer:** **Contractual unpaid benefit → TADM clock**; **advisory-norm gap → negotiate + TAFEP**; mediation does **not** pause EP cancel — run STVP on a separate track.

Parent guide covers **what money might be owed** and the STVP ask on cancel — [retrenchment on EP](/guides/retrenchment-ep-benefits). This companion is the **dispute fork**: when unpaid quantum goes to **TADM**, when MOM points non-unionised staff to **TAFEP**, and how pass clocks refuse to wait for mediation.

## Fork: contract vs advisory norm

| Situation | Typical path (verify live) |
| --- | --- |
| Contract / collective agreement **names** a retrenchment benefit and HR does not pay | **TADM** — treat like other contractual money claims; left-employment filing windows are tight (often **6 months** from last day — read live TADM text) |
| **No** contractual provision; employer below TAMEM advisory norms | Negotiate in writing; MOM FAQ steers many non-unionised employees toward **TAFEP** engagement rather than inventing a statutory cheque |
| Unpaid **salary / notice / unused AL** (separate from retrenchment benefit) | **TADM** — [salary disputes](/guides/salary-dispute-tadm-mom) · [AL encashment](/guides/annual-leave-encashment-notice-offset-ep-singapore) |
| Selection looks discriminatory / bad-faith “performance” re-label | TAFEP / counsel — different from pure quantum fights |

Retrenchment benefit is usually **contractual or negotiated**, not a universal Employment Act payout. Read the letter and the handbook the night you get them.

## Release / waiver traps

- Get the package **in writing** before you sign a release that waives salary, leave, or benefit claims.  
- “Sign today or the offer expires” is a negotiation tactic — still screenshot the draft and the MOM FAQ.  
- Misconduct dismissal language when the facts are redundancy is a different fight; counsel helps when the letter smells wrong.

## Pass fear — mediation does not extend EP

TADM / TAFEP do **not** pause cancellation:

1. Ask HR **in writing** for the longest **STVP** MOM allows on cancel — [between jobs](/guides/between-jobs-stvp-singapore)  
2. File while still in Singapore if the left-employment clock is tight  
3. You **cannot work** on STVP — new IPA before start — [career pivots](/guides/career-pivots-singapore)  
4. Start **IR21** early — [tax clearance](/guides/tax-clearance-when-leaving)

## Decision rule

**Named contractual benefit unpaid → TADM clock. Advisory-norm gap → negotiate + TAFEP per MOM FAQ. Salary/leave/notice arrears → TADM regardless.** Keep the pass/STVP calendar on a separate track from the quantum fight.
