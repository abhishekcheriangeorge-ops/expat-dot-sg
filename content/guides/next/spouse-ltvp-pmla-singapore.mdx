r/askSingapore’s “we just ROM’d — how long for LTVP?” threads collapse **PMLA**, **Letter of Eligibility**, **spouse LTVP**, and **spouse PR** into one clock. They are different products. This guide is the **ICA spouse LTVP** lane (SC or PR sponsor). Permanent residence stays on [PR for spouse](/guides/pr-for-spouse-singapore). Work rights after LTVP live on [PLOC / LOC](/guides/ploc-loc-ica-ltvp-singapore).

## SC vs PR sponsor — the fork people miss

| Sponsor | PMLA available? | Published LTVP processing orientation |
| --- | --- | --- |
| **Singapore citizen** | **Yes** — free Pre-Marriage LTVP Assessment before marriage | Up to **6 months** without PMLA; **~6 weeks** if PMLA was completed before marriage |
| **Singapore PR** | **No** published PMLA path | Most within **6 weeks** when documents are in order (some longer) |

PMLA is an **SC + non-resident** product. A PR spouse cannot “do PMLA to speed things up” because ICA’s PMLA pages are written for citizen sponsors. Arrival-oriented MOM vs ICA category confusion stays on Move’s [LTVP overview](/guides/ltvp-singapore).

## What PMLA is (and is not)

ICA’s Pre-Marriage LTVP Assessment is **free**. It helps an SC–NR couple:

1. Check whether the intended foreign spouse is **likely eligible** for LTVP (marriage does **not** guarantee stay)  
2. Shorten the later LTVP file to about **6 weeks** instead of up to **6 months**  
3. Surface hard conversations (income, housing, immigration history) **before** ROM  

Published PMLA orientation:

| Topic | Live ICA note |
| --- | --- |
| Who logs in | **SC** with Singpass; NR supplies passport / particulars |
| Draft lifespan | Submit within **7 days** of starting the draft or it is auto-removed |
| Processing | Within **1 month** when information is in order; some longer |
| Positive outcome | **Letter of Eligibility (LLE)** — valid for **1 year** to support a later LTVP file |
| What LLE is not | **Not** an LTVP, **not** work rights, **not** a PR promise |

ICA warns that in a small number of cases PMLA and later LTVP outcomes can diverge if circumstances or submitted particulars change between the two filings. Treat a positive PMLA as planning clarity, not a voucher.

Existing / former **Work Permit** (including Training Work Permit) holders who want to marry an SC or PR — in Singapore or overseas, civil / religious / customary — must first get **MOM Controller of Work Passes approval**. Skipping that step can cost work privileges and entry.

## After marriage — file the actual LTVP

The local spouse sponsors on ICA e-Service with **Singpass**. Every applicant must review declarations (Singpass or ICA-issued credentials). ICA recommends starting only after eligible people already have Singpass — account approval can take **2–5 working days**.

Fees ICA publishes for LTVP (verify live; non-refundable):

| Stage | Fee |
| --- | --- |
| At submission | **S$45** per application |
| At formalities | **S$60** LTVP issuance + **S$30** Multiple Journey Visa if applicable |

Renew at least **3 months** before expiry. Renewed validity starts from **issuance**; leftover old validity is **not** carried forward.

EP / S Pass / DP households switching onto spouse LTVP after marrying an SC/PR need sequencing so cancel day does not create a stay gap — [between jobs / STVP](/guides/between-jobs-stvp-singapore) and Move’s [Dependant’s Pass](/guides/dependant-pass-singapore) for the EP-family lane.

## LTVP ≠ PR (and ≠ work)

Spouse LTVP is a **stay** product. It does not mint a blue IC. Many couples use months or years of LTVP residence before a [spouse-sponsored PR](/guides/pr-for-spouse-singapore) file; that is a household strategy, not a published mandatory wait.

LTVP alone does **not** authorise local employment. Eligible spouses (and unmarried children under 21) of SC/PR request **PLOC** with the LTVP file or later, or an employer **LOC** — [PLOC / LOC playbook](/guides/ploc-loc-ica-ltvp-singapore).

## Decision rule

If you are an **SC** marrying a foreigner and stay matters, run **PMLA before ROM**, keep the LLE inside its **1-year** window, then file spouse LTVP with coherent docs. If you are a **PR** sponsor, skip PMLA folklore and budget the published **~6-week** LTVP lane (some longer). Treat agents as form-fillers at best, and do not confuse LTVP IPA with PR.
