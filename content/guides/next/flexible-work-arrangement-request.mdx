**Short answer:** From **1 Dec 2024**, employers must **consider** formal FWA requests and reply in writing (~**2 months**). Approval is not mandatory — and TG-FWAR is not a Bali-WFH visa for EP/S Pass holders.

From **1 December 2024**, Singapore’s [Tripartite Guidelines on Flexible Work Arrangement Requests (TG-FWAR)](https://www.mom.gov.sg/employment-practices/good-work-practices/flexible-work-arrangements) set a formal request-and-reply process. Reddit’s hot take that “MOM now forces WFH” is wrong. The real change: employers must **properly consider** formal requests and answer in writing — approval is still a business call.

EP and S Pass employees on a contract of service are not carved out of the guidelines. Pass type does not create a right to Bali-WFH either.

## What “formal FWA” means

| Idea | Reality under TG-FWAR |
| --- | --- |
| Flexi-place (WFH / hybrid) | Can request; not guaranteed |
| Flexi-time / compressed hours | Same process |
| Informal “can I WFH Friday?” | Outside the Guidelines’ formal track |
| Employer must approve | **No** — must consider and respond |
| Written reply deadline | Within **2 months** of a formal request |
| Rejection reason | Should be **reasonable business-related** grounds |

## How to file so it counts

If HR already publishes a formal FWA form, **use that form**. If they do not, put a written request with at least:

1. Date of request  
2. Type of FWA + expected frequency / duration  
3. Reason  
4. Proposed start (and end, if time-bound)  

MOM’s PDF includes a sample template (Annex A). Probation completion is the usual eligibility gate in the Guidelines — verify your employer’s stated process.

## Rejection language that fails the smell test

Business grounds can include client face-to-face needs, rostered coverage, data-security constraints, or team coordination. “We do not have an FWA policy” is **not** a free pass to ignore the request — employers still assess and reply. “I want to watch you work” as the sole reason is the kind of language TAFEP advice flags as weak.

Overseas WFH for an EP holder is a separate stack: immigration in the destination country, Singapore tax residency days, and employer PE risk. MOM’s public FAQs note TG-FWAR is generally about arrangements **in Singapore**; treating Bali as a formal FWA outcome without counsel is how Reddit threads end in tax panic — see also [career pivots](/guides/career-pivots-singapore) and [IRAS residency](/guides/iras-tax-residency-filing).

## When sick leave / MC is the real issue

If you cannot work, that is leave — [Employment Act leave & notice](/guides/employment-act-leave-notice-ep) — not an FWA request to “WFH while infectious.” If you *can* work but need place/time flexibility around treatment, a time-bound formal FWA is the tool Reddit meant in the chemo / medical threads.

## Practical checklist

1. Read the company FWA SOP before inventing a free-form email  
2. Ask for a **time-bound** trial if permanent hybrid is a hard sell  
3. Keep the written rejection — it is the artefact TAFEP / NTUC conversations start from  
4. Do not confuse FWA with unpaid leave, annual leave, or parental leave schemes  
5. Escalation for process failures: TAFEP; for salary/dismissal fights: [TADM](/guides/salary-dispute-tadm-mom)
