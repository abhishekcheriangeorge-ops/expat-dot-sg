## Letter of Eligibility — one-year use-it window

| Fact | Detail |
| --- | --- |
| Who gets LLE | SC–NR couples with a **positive** PMLA |
| Validity | **1 year** to support a later **LTVP** file after marriage |
| What LLE is not | Not an LTVP · not work rights · not a PR promise · **not** a renewal voucher |
| Miss the year | Re-assess / re-file per ICA’s live PMLA path — do not invent “expired LLE still speeds to 6 weeks” |

PMLA remains **SC-only**. PR sponsors skip PMLA folklore and use the published spouse-of-PR LTVP lane.

## Renewal clocks (existing spouse LTVP)

| Rule | Detail |
| --- | --- |
| When to file | At least **3 months** before current LTVP expiry |
| New validity | From **issuance** (after issuance fee) |
| Leftover days | **Not** carried forward |
| Fees (verify live) | Same family as first issue: **S$45** submission · **S$60** issuance · **S$30** MJV if applicable |
| PMLA on renewal? | **No** — PMLA is a **pre-marriage** assessment, not the renewal e-Service |

Sponsor still logs in with Singpass. Work rights (PLOC / LOC) are a separate stack — [PLOC / LOC](/guides/ploc-loc-ica-ltvp-singapore). Aiming for blue IC later stays on [PR for spouse](/guides/pr-for-spouse-singapore).

## Decision rule

**Use LLE inside one year after marriage for the first LTVP → renew on the LTVP e-Service ≥3 months out → never treat PMLA as a renewal form.** Parent overview stays on [spouse LTVP + PMLA](/guides/spouse-ltvp-pmla-singapore).
