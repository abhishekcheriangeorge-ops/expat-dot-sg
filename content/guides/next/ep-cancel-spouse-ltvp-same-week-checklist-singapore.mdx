**Short answer:** Same week — **HR STVP ask + IR21 + ICA spouse LTVP (+ PLOC if needed)** — STVP is stay-only and PMLA is not a layoff hack.

r/askSingapore’s layoff week often burns **five calendar days** debating folklore before anyone emails HR or opens ICA e-Service. Product chooser lives on [EP job loss → spouse LTVP bridge](/guides/ep-job-loss-spouse-ltvp-bridge-singapore). This companion is the **same-week checklist** when your spouse is already an **SC or PR**.

## Day-of-notice checklist

| # | Action | Why |
| --- | --- | --- |
| 1 | Email HR: cancel date + request **longest STVP** MOM allows (up to **90 days**) | Default HR behaviour is often shorter |
| 2 | Confirm **DP / family passes** tied to the EP fall with cancel | Do not assume the trailing spouse’s DP floats |
| 3 | Start / confirm **IR21** timing and final-pay withhold | [Tax clearance](/guides/tax-clearance-when-leaving) |
| 4 | Local spouse opens ICA **spouse LTVP** e-Service (Singpass) | Stay bridge beyond STVP |
| 5 | Tick **PLOC** with the LTVP file if dual income is real | LTVP alone is stay — [PLOC / LOC](/guides/ploc-loc-ica-ltvp-singapore) |
| 6 | Inventory lease / school / helper / who holds each contract | STVP is not a housing plan |
| 7 | If exiting instead of bridging | Switch to [leaving playbook](/guides/leaving-singapore-playbook) the same week |

## Do not burn the week on these myths

| Myth | Safer move |
| --- | --- |
| “Wait until STVP day 1 to file LTVP” | Open ICA as soon as marriage / sponsor facts support it — case-by-case while still on EP is peer practice, not a published ban |
| “PMLA after layoff speeds LTVP” | PMLA is **pre-marriage**; it is not a post-layoff hack |
| “Graduate LTVP = spouse LTVP” | Different ICA rows |
| “STVP = keep working” | Cancel ends work rights immediately |
| “PR auto-starts when EP dies” | Still discretionary — spouse PR is a separate file |

Retrenchment **money** stays on [retrenchment on EP](/guides/retrenchment-ep-benefits). Generic STVP choreography on [between jobs](/guides/between-jobs-stvp-singapore).

## Decision rule

**Same week: HR STVP ask + IR21 + ICA spouse LTVP (+ PLOC if needed) + household inventory.** Parent framing stays on [EP → spouse LTVP bridge](/guides/ep-job-loss-spouse-ltvp-bridge-singapore).
