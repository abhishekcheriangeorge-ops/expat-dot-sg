r/askSingapore’s layoff threads call every temporary stay document a **“Special Pass.”** For **Employment Pass** cancellation, MOM’s published path is a **Short-Term Visit Pass (STVP)** requested through EP eService — up to **90 days** from the application date. Family cascade, work ban, and travel risk live on [between jobs / STVP](/guides/between-jobs-stvp-singapore). This companion kills the **Special Pass mix-up**.

## EP cancel → STVP (not WP Special Pass)

| Situation | Published stay document |
| --- | --- |
| **EP** cancelled / expired while the holder remains in Singapore | Employer requests **STVP** via EP cancel / promptly after expiry — [cancel EP](https://www.mom.gov.sg/passes-and-permits/employment-pass/cancel-a-pass) |
| **Dependant’s Pass** cancelled / expired while still in Singapore | Same idea — request **STVP** on the DP cancel rail |
| **Work Permit** cancelled / expired while the worker remains | Employer path often issues a **Special Pass** tied to departure — [cancel Work Permit](https://www.mom.gov.sg/passes-and-permits/work-permit-for-foreign-worker/cancel-a-work-permit) |

Do **not** tell HR to “print a Special Pass” for an EP holder because a construction-site friend used that phrase. Wrong product → wrong portal → overstay risk.

## What STVP still is (and is not)

| Topic | Reality |
| --- | --- |
| Work | **No.** Cancel ends work rights immediately |
| Length | Up to **90 days** per MOM EP cancel guidance — confirm what HR actually selected |
| Who requests | Employer / agent — ask **in writing** for the longest available STVP |
| Re-entry | Leaving on STVP can end return without a fresh visa / IPA — treat travel as high-risk |
| Family | Related DPs / LTVPs under the EP usually cancel with the main pass — same-week plan |
| Tourist VP extension | Different ICA rail — [short-term visit pass extension](/guides/short-term-visit-pass-extension) |

Married to an **SC/PR**? STVP is only the short buffer — [EP job loss → spouse LTVP bridge](/guides/ep-job-loss-spouse-ltvp-bridge-singapore).

## Extensions — do not invent ICA counter magic

MOM’s general “extend stay” FAQ covers more time to **leave** or to **get a pass issued/renewed**, with a **7–14 day** before-expiry submission window for many requests. Late filings risk overstay fines; early filings can be rejected. ICA counters do **not** casually extend an MOM-issued STVP because a friend said so — follow MOM’s live form / portal path for *your* pass type.

Special Pass language on that FAQ often rides **Work Permit / departure** fact patterns. Read the row that matches your pass, not the Reddit title.

## Decision rule

**EP cancel → ask HR for STVP (up to 90) → stay only → plan family the same week.** Parent depth stays on [between jobs](/guides/between-jobs-stvp-singapore); money/exit on [retrenchment](/guides/retrenchment-ep-benefits) and [leaving playbook](/guides/leaving-singapore-playbook).
