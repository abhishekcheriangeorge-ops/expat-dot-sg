r/askSingapore’s post-birth threads mix three different legal events: **Singapore birth registration**, **foreign citizenship of the baby**, and **Permanent Residence**. A parent’s blue IC does **not** mint PR for the child. ICA’s published family path is a **sponsored PR application** for an **unmarried child aged below 21** born within a legal marriage to — or legally adopted by — a Singapore citizen or PR.

## What ICA actually lists

| Eligibility ICA publishes | Who logs in |
| --- | --- |
| Unmarried child **under 21**, born in a legal marriage to an SC/PR parent, or legally **adopted** by an SC/PR | The **parent** sponsors via ICA e-Service with Singpass |
| Spouse of SC/PR | Spouse sponsors (different form path) |
| Aged parent of an SC aged 21+ | Child sponsors (SC-only parent path — not PR sponsors) |

This guide is the **child** row only. Adult PTS / EP-holder PR strategy stays on [PR application strategy](/guides/pr-application-strategy).

<OfficialSource>
Eligibility table and fees: [ICA — Becoming a Permanent Resident](https://www.ica.gov.sg/reside/PR). NS liability warnings on the same page — read before you tick “submit” for a son.
</OfficialSource>

## Birth in Singapore ≠ Singapore PR (or SC)

Place of birth on a Singapore birth certificate does **not** by itself create PR or citizenship for a foreign child. Citizenship follows bloodline / registration rules under ICA’s citizenship pages; PR follows a **discretionary** application. Forum lines like “baby born here so automatic PR” are wrong twice — wrong for PR and usually wrong for SC unless a parent’s citizenship path applies.

Practical first week for many PR parents:

1. Register the birth (LifeSG / ICA birth process as eligible)  
2. Secure the child’s **foreign passport** / consular registration if needed  
3. Decide whether to **sponsor PR now**, wait, or pursue citizenship later if an SC parent path exists  

## Fees ICA publishes (verify live)

| Stage | Published fee |
| --- | --- |
| At submission | **S$100** per application |
| At completion of formalities | **S$20** Entry Permit + **S$50** for a 5-year Re-Entry Permit + **S$50** Singapore Identity Card (when IC is issued) |

Processing: ICA cites about **6 months** when documents are in order; some files take longer. Outcomes arrive by email / MyICA. Every applicant added to the form must review declarations (Singpass or ICA-issued credentials).

## NS is not a footnote for sons

ICA’s PR page states that male applicants granted PR **under parents’ sponsorship** (and as foreign students) are **liable for National Service**. They register around **16½** and are scheduled for full-time NS at the earliest opportunity from **18**, with the usual pre-tertiary deferment limits — **not** university deferment.

Reddit’s “don’t apply PR for a baby boy” advice is risk framing, not ICA policy. If you sponsor a son:

- Read [CMPB](https://www.cmpb.gov.sg/) and [citizenship / NS implications](/guides/citizenship-ns-implications) **before** you treat PR as a school-fee hack  
- Renouncing later without completing NS can damage **his** and **the family’s** future long-term immigration facilities — see [renouncing PR](/guides/renouncing-pr-singapore) and [NS Exit Permit](/guides/ns-exit-permit-pr-families)

## Approval realism

ICA assesses family ties, economic contributions, qualifications, age, family profile, and length of residency. A parent already holding PR helps family-ties optics; it is **not** a guarantee. Rejections happen for newborns and teens alike — use [PR rejection / reapply](/guides/pr-rejection-reapply) hygiene rather than spam-filing every quarter.

Documents: certified true copies + official English translations where needed. ICA accepts embassy / notary translation patterns listed on the PR page; it does **not** endorse commercial “PR agents.”

## After IPA — treat it like adult PR formalities

If approved, the child still needs **formalities**: Entry Permit, Re-Entry Permit discipline for travel, and IC issuance when age-eligible. Fold the child’s REP into the household calendar on [after getting PR](/guides/after-getting-pr-checklist) and [REP overseas](/guides/re-entry-permit-pr-overseas). Do not assume the parent’s REP covers the child’s travel status.

## Decision rule

Sponsor a child PR application when you intend **roots + NS honesty** for sons, not because the birth cert says Singapore. Register the birth, secure foreign papers, read CMPB if the child is male, then file the ICA child path with fees and a six-month patience budget.
