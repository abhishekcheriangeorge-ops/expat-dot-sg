## Renewal calendar ≠ only risk window

S Pass carries **employer quota (DRC)** and a **monthly levy**. Mid-cycle hiring, sector reclassification folklore, or stepped salary-table changes can blow the “we’ll sort it at renewal” plan months early. Employment Pass still has **no** DRC quota — do not let HR blur the products.

| Shock mid-cycle | Safer reading |
| --- | --- |
| Firm hires more S Pass / WP heads | DRC headroom can vanish **before** your renewal date |
| “Levy went up; take a cut or resign” | Levy is an employer cost — salary cuts still need live S Pass / family-pass maths |
| “We’ll move you to EP when quota bites” | EP is a **new file** — [upgrade path](/guides/s-pass-to-ep-upgrade-in-singapore) · [packaging](/guides/s-pass-to-ep-upgrade-packaging-singapore) |
| “DP is safe until renewal” | Family privileges track separate tables — [Dependant’s Pass](/guides/dependant-pass-singapore) |

## Mid-cycle checklist

1. Ask HR for a written DRC / levy snapshot when the firm is hiring other foreign workers — not only at your renewal month.  
2. If EP upgrade is the escape hatch, start FCF + COMPASS packaging early — do not wait for a refusal letter.  
3. Model family-pass salary floors separately from S Pass qualifying salary.  
4. Keep the S Pass valid while any EP files — cancel-early folklore feeds [between-jobs STVP](/guides/between-jobs-stvp-singapore) messes.  
5. Verify live MOM levy/quota tables whenever someone cites a WhatsApp screenshot.

## Decision rule

**Watch DRC and levy mid-cycle — renewal day is too late if the firm’s headcount maths already moved.**
