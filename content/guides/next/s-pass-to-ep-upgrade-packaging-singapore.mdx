## Raise letter ≠ EP file

An in-country upgrade is still a **new EP application**. Packaging failures usually sit in three buckets: **fixed monthly** vs total package, missing **FCF** advertising proof, and invented **COMPASS** points from the old S Pass offer.

| Packaging miss | Safer reading |
| --- | --- |
| Offer shows OTE / allowances only | Stage 1 and C1 care about **fixed monthly** — [C1 packaging](/guides/compass-c1-fixed-salary-packaging-singapore) |
| “We already employed them on S Pass” | FCF clocks still apply unless a published exemption fits |
| Degree assumed from LinkedIn | C2 needs verifiable awarding-body proof — [C2 edges](/guides/compass-c2-degree-verification-edges-singapore) |
| SAT screenshot from last year | Re-run against **this** salary, title, and firm mix |

## Packaging checklist

1. One-page fixed monthly salary confirmation matching the EP form (not “package”).  
2. MyCareersFuture / FCF ad window screenshots + dates unless exempt.  
3. Degree / equivalent pack with awarding body names that match the certificate.  
4. Fresh COMPASS / SAT run with current firm diversity inputs.  
5. Written Plan B: remain on valid S Pass if EP is refused — do not cancel early.

## Decision rule

**Package the EP like a new hire file — a raise on S Pass is evidence for HR, not a MOM conversion toggle.**
