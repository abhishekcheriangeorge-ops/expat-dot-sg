**Short answer:** Report on ICA’s **Loss of IC** e-Service from abroad, fly home on **passport** (+ **REP** for PRs), and **replace/collect in Singapore** — embassies cannot issue a temporary IC.

r/askSingapore’s “I lost my blue card in Bangkok / London” threads ask the embassy for a temporary IC. **Missions do not replace Singapore Identity Cards.** Fees, the 14-day report clock, and Digital IC habits live on [lost / stolen NRIC](/guides/lost-replace-nric-pr-singapore). This companion is the **overseas → return → collect in Singapore** layer.

EP / S Pass / DP **plastic** loss is still MOM — [lost work pass card](/guides/lost-replace-work-pass-card) — not this rail.

## Overseas operating sequence

| Step | When | Detail |
| --- | --- | --- |
| 1. Report loss via ICA **Loss of IC** e-Service (Singpass) | ASAP | ICA asks you to report immediately and apply for replacement **within 14 days** of the report |
| 2. Keep travelling on a **valid passport** (+ REP print-out for PRs if that is your travel stack) | Until return | IC is not your boarding pass; passport / REP rules still apply — [REP](/guides/re-entry-permit-pr-overseas) |
| 3. Use **Singpass Digital IC** where the counterparty accepts it | Day-to-day | Does **not** waive the physical replacement filing |
| 4. Complete replacement / collection on **next return to Singapore** | In SG | ICA’s published overseas path; collection is **in person** in Singapore |

If you cannot hit the 14-day window because you are stuck abroad, contact ICA’s IC unit path named on the live Loss page rather than inventing a mission workaround.

## What embassies will not do

- Issue a temporary Singapore IC or “consular NRIC letter” that substitutes for ICA replacement  
- Collect or courier a new IC to you overseas — ICA collection remains **in Singapore**  
- Convert a foreign police report into an ICA waiver of the e-Service report

A local police report still helps banks / insurers if the wallet was stolen; ICA says a police report is **not required** for the IC replacement itself.

## Return-week checklist

1. Confirm the Loss e-Service / replacement application status before you fly if you already reported abroad.  
2. Book ICA (or SingPost, if offered on your notice) **collection** within **three months** of approval.  
3. Bring the identity docs ICA’s collection page lists — typically passport and any slip / email named in the notice.  
4. Once submitted, a **new** IC is issued — no refund if the old card turns up in your suitcase later.

Fees stay on the parent: typically **S$100** first loss / **S$300** subsequent (verify live).

## Decision rule

Report on ICA’s e-Service from wherever you are, fly home on passport (+ REP for PRs), replace and collect **in Singapore**.
