## Appeals are employer-owned

MOM’s appeal page is written for the **employer / agent**. Candidates cannot file a personal appeal email and expect a case ID. The published window is **3 months** from rejection; most appeals process in about **6 weeks** when the advisory is actually answered.

| Folklore | Safer reading |
| --- | --- |
| “SAT said 90 — appeal will fix it” | Self-Assessment Tool is planning input, not a veto override |
| “I’ll email MOM myself” | Candidate enquiries are not the appeal channel |
| “Appeal pending = keep working” | No IPA / cancelled pass ≠ work rights while you wait |
| “Resign now, appeal later” | Weak appeals + no job leave you on visit status |

## Playbook before you burn bridges

1. Get the **rejection advisory** text from HR (EP eService / letter) — not a verbal summary.  
2. Map each advisory line to a **new fact**: fixed salary, COMPASS inputs, degree campus proof, FCF ad ID / exemption, employer tax hygiene.  
3. Ask HR: appeal vs **cleaner refile** — sometimes a fixed-salary uplift + completed [FCF clock](/guides/fcf-mycareersfuture-14-day-clock-ep-singapore) beats a thin appeal.  
4. Do **not** resign overseas on “we’ll appeal” alone — keep a lawful stay / return plan.  
5. If the pass never issues, issuance clocks are irrelevant until approval — then [career pivots](/guides/career-pivots-singapore) sequencing applies.

## Decision rule

**No advisory + no new facts → no appeal theatre.** Either fix the file or keep the current job / visit plan intact.
