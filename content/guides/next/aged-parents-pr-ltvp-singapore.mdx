r/askSingapore’s “bring Mum over” threads mix **social visit**, **LTVP**, and **PR** as if they were one form. ICA publishes two different products. **Aged-parent PR** is listed only for parents of a **Singapore citizen aged 21+**. **Parent LTVP** is open to parents of an **SC or PR** (with sponsor rules by the child’s age). Parents-in-law are **not** eligible on the LTVP parent row. Renewal clocks and sponsor-change rules: [aged-parent LTVP renewal](/guides/aged-parent-ltvp-renewal-sponsor-change-singapore).

## Product chooser

| Goal | ICA product | Who can sponsor |
| --- | --- | --- |
| Permanent residence for a parent | **PR — aged parent of an SC** | Singapore **citizen** child aged **21+** logs in with Singpass |
| Longer stay without PR | **LTVP — parent of SC/PR** | If child is **21+**: that SC/PR child sponsors. If child is **under 21**: a local SC/PR sponsor aged 21+ is required |
| In-laws | Not on the parent LTVP row | Do not file under “parent” folklore |

PR children who want parents here for care visits usually start with **LTVP** (or short social visits), not a PR application that ICA’s eligibility table does not list for them.

<OfficialSource>
PR eligibility row: [ICA — Becoming a Permanent Resident](https://www.ica.gov.sg/reside/PR). Parent LTVP row + fees: [ICA — Becoming a Long-Term Visit Pass Holder](https://www.ica.gov.sg/reside/LTVP).
</OfficialSource>

## “Aged” has no public number on the PR page

ICA’s live PR page says **“Aged parent of a Singapore citizen of at least 21 years old.”** It does **not** publish a fixed parent age (55 / 60 / retirement age) on that eligibility table. Forum claims that “ICA only accepts parents over X” are **peer folklore**, not a citeable rule. Call or write ICA if you need case-specific clarification — do not pay an agent for a invented cutoff.

Approval remains discretionary. ICA’s published assessment themes (family ties, economic contributions, qualifications, age, family profile, length of residency, integration, roots) still apply. A dependent retiree with no Singapore history can be eligible to **file** and still be refused.

## Fees and clocks (verify live)

### Parent PR (SC sponsor)

| Stage | Published fee / clock |
| --- | --- |
| Submission | **S$100** per application |
| Formalities | **S$20** Entry Permit + **S$50** 5-year REP + **S$50** IC (when issued) |
| Processing | About **6 months** when documents are in order; some longer |

The PR checklist PDF has an **additional aged-parent** document block (including non-applying children). Follow the live PDF, not an agency binder — [checklist](https://www.ica.gov.sg/docs/default-source/ica/ipses/pr-document-checklist.pdf).

### Parent LTVP (SC or PR sponsor)

| Stage | Published fee / clock |
| --- | --- |
| Submission | **S$45** per application |
| Issuance | **S$60** LTVP + **S$30** Multiple Journey Visa if applicable |
| Processing | Most within **6 weeks** when documents are in order; some longer |
| Renewal | Apply at least **3 months** before expiry — renewed validity starts from issuance; leftover old validity is **not** carried forward — deep dive: [parent LTVP renewal / sponsor change](/guides/aged-parent-ltvp-renewal-sponsor-change-singapore) |

All listed fees are non-refundable. Formalities after IPA still require the parent to complete ICA’s issuance steps in person when instructed.

## Housing, money, and medical realism

LTVP / aged-parent PR do **not** turn parents into subsidised citizens. Peers routinely underestimate:

- Private **hospital bills** without a workable insurance plan  
- Housing — parents on LTVP generally cannot buy HDB the way SC/PR households can  
- What happens to the parent’s stay if the **sponsor** dies, emigrates, or loses status  

Budget insurance and caregiver capacity **before** you treat LTVP as a soft landing. Orientation for expat medical cashflow stays on [health insurance](/guides/health-insurance-expat); this guide will not invent a premium quote.

## Citizenship for a parent who already holds PR

A parent who is already a PR may later apply for citizenship under ICA’s citizenship eligibility rows (including aged-parent themes where published). That is a **separate** discretionary file — see [citizenship application](/guides/singapore-citizenship-application). Rejections after decades of PR are a known forum pattern; do not equate “eligible to apply” with “will get pink IC.”

## Agents and appeals

ICA states it has **no affiliation** with commercial immigration specialists for PR or LTVP. Use [appeal e-Service](https://www.ica.gov.sg/reside/reside-appeals) paths when refused; spam-refiling identical parent PR every quarter burns money without new substance — [rejection / reapply](/guides/pr-rejection-reapply).

## Decision rule

If you are an **SC aged 21+** and want permanent status for a parent, file the **aged-parent PR** row knowing approval is hard and discretionary. If you are a **PR**, or you need stay without PR, use the **parent LTVP** row (in-laws excluded). Price medical risk and housing before the emotional “Mum should get PR too” conversation.
