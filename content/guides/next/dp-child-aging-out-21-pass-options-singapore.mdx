**Short answer:** **Under-21 is the product.** Start Student’s Pass or own work-pass filings while DP is still valid — the birthday is not a soft reminder.

Parent map: [Dependant’s Pass](/guides/dependant-pass-singapore). This companion is the **child turning 21** cliff Reddit treats as “MOM will just renew one more year.”

## The hard gate

MOM’s Dependant’s Pass lane for children is **unmarried and under 21**. The birthday is not a soft reminder — it is the eligibility cliff. A plastic card that still shows ink does not override the published age rule once the child ages out.

| Folklore | Safer reading |
| --- | --- |
| “We’ll renew DP for uni year 1” | Renewal still needs the child to clear the under-21 / unmarried tests at the point MOM assesses |
| “Student Pass is automatic after DP” | ICA Student’s Pass is a **separate** filing with school / course gates — [Student’s Pass](/guides/student-pass-singapore) |
| “Just put them on LTVP” | LTVP is not a default child dump lane — relationship and sponsor rules still apply — [LTVP](/guides/ltvp-singapore) |
| “They can job-hunt on expired DP” | Overstaying or working without a pass is the failure mode — plan the next status **before** cancel |

## Six-month runway (orientation)

1. **Confirm the birthday vs pass expiry** — which clock hits first?  
2. **School path** — if still in full-time study that qualifies, start ICA Student’s Pass paperwork with the institution early.  
3. **Work path** — own [Employment Pass](/guides/employment-pass-singapore) / [S Pass](/guides/s-pass-singapore) needs an employer, salary floors, and (for EP) COMPASS / FCF — not a parental upgrade button.  
4. **Household cancel risk** — if the principal EP dies mid-transition, DPs cascade; STVP is stay, not a career bridge — [between jobs](/guides/between-jobs-stvp-singapore).  
5. **Do not book non-refundable uni housing abroad** until the Singapore stay status for the gap months is written down.

## Decision rule

**Under-21 is the product.** Everything else (Student’s Pass, own work pass, LTVP) is a **different** application with its own evidence — start it while the DP is still clearly valid, not after the birthday cake.
