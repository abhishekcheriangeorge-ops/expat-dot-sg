**Short answer:** **Safety first**, then a **written trail** and **TAFEP** if HR fails — pass fear is a planning constraint (IPA / notice / TADM), not a veto on reporting.

r/askSingapore’s harassment threads freeze on one sentence: “If I report, they cancel my EP.” Channels and evidence habits live on [workplace harassment for EP / S Pass](/guides/workplace-harassment-tafep-ep). This companion is the **pass-clock plan** so fear does not become a veto.

## Safety first, then the paper trail

| Priority | Action |
| --- | --- |
| Immediate danger | Leave the space; **999** / [emergencies](/guides/emergencies-995-999-embassies) |
| Same day | Dated notes + lawful exports of chats / email |
| Written report | HR / whistleblowing — or alternate channel if the harasser *is* HR |
| External | **TAFEP** if HR stalls, is conflicted, or has no policy — [contact](https://www.tal.sg/tafep/contact-us) |
| Parallel | Quiet job search / IPA sequencing — [career pivots](/guides/career-pivots-singapore) |

A TAFEP call does **not** auto-cancel your pass. Employment end (resign / dismiss / retrench) is what triggers cancel clocks.

## Pass-fear planning matrix

| Scenario | Operate like this |
| --- | --- |
| You can stay and the culture can change | Written stop + HR + TAFEP; keep working while the file moves |
| You need to leave fast for safety | Notice / salary in lieu still matter — [leave & notice](/guides/employment-act-leave-notice-ep); do not invent “harassment = free walk” |
| Best path is a new employer | Secure **IPA before** resign when you can |
| Dismissed after a good-faith report | Wrongful-dismissal path via **TADM** — [salary / TADM](/guides/salary-dispute-tadm-mom) and [filing clocks](/guides/tadm-salary-claim-ep-filing-clocks-singapore) |
| Pass already ending | STVP / exit choreography — [between jobs](/guides/between-jobs-stvp-singapore) |

MOM telling someone to “pay short notice” is about **contract notice**, not a finding that harassment is fine.

## Decision rule

**Safety → written trail → TAFEP if needed → plan IPA / notice / TADM on purpose.** Parent channel map stays on [workplace harassment](/guides/workplace-harassment-tafep-ep).
