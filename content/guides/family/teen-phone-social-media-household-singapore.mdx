IS cohorts normalise **always-on group chats**. Dual-career households on r/askSingapore keep fighting the wrong war (“no phone ever”) instead of writing a **household contract** that survives mocks, travel weeks, and 11pm class WhatsApps.

Mental-health rails: [teen counselling](/guides/teen-mental-health-school-counselling-singapore) and [mental health resources](/guides/mental-health-resources). Exam load: [IB vs A-Level](/guides/secondary-ib-alevel-pathways-singapore). This guide is **device + social ops** at home.

## What the contract should name

| Clause | Example household rule | Why it matters here |
| --- | --- | --- |
| **Sleep window** | Phones charge outside bedrooms after 22:30 on school nights | Humidity + FOMO + early buses |
| **Exam blackout** | No new game downloads in mock weeks | Panic installs are a tell |
| **Group-chat hours** | Class chat muted 23:00–06:30; urgent = call parent | IS project chats ignore your timezone guilt |
| **Location sharing** | On for first independent Grab/bus months | Safety without full surveillance theatre |
| **Photo / story consent** | No posting siblings / home address | Condo + school ID leakage |
| **Consequence ladder** | Written, boring, pre-agreed | Improvised bans teach nothing |

<OfficialSource>
Family digital-safety orientation: [CSA](https://www.csa.gov.sg/). School well-being policies vary — ask the counsellor what the school’s device code actually enforces versus aspirational handbook language ([MOE](https://www.moe.gov.sg/) for system framing).
</OfficialSource>

## Dual-career failure modes

| Failure | Fix |
| --- | --- |
| One parent bans; the other undermines on FaceTime | Joint contract signed by both adults |
| Rules only appear after a crisis | Draft in a calm week; revise quarterly |
| “No social media” while CCA requires Telegram | Allow listed apps with time bounds |
| Monitoring apps without a conversation | Disclose tools; secrecy destroys trust faster than TikTok |

Travel weeks need a temporary amendment — same as [bus/pickup ops](/guides/international-school-bus-pickup-dual-career-singapore) when one adult is off-island.

## When to escalate beyond house rules

- Sleep collapse + grade freefall  
- Group-chat bullying / exclusion that does not stop after one adult intervene  
- Self-harm language or sudden withdrawal — go to [teen counselling](/guides/teen-mental-health-school-counselling-singapore) without negotiating another screen-time chart first

## A one-page starter contract

1. Devices sleep in the kitchen on school nights.  
2. Class chats mute overnight; teachers email for true emergencies.  
3. New apps need a 24-hour parent look (not a veto theatre).  
4. Public stories never show unit numbers, passes, or uniforms with names.  
5. Review date: first Sunday each term.

Write it. Put it on the fridge. Boredom is a feature.
