Night coughs and PE whistle days collide hard. Dual-career EP/DP households on r/askSingapore keep arguing “just a cold” at 06:20 while both calendars stay green — then learning that **inhaler kits and named coverage owners** beat dual muted Slack.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Haze weeks: [haze PSI coverage](/guides/dual-career-haze-psi-school-closure-coverage-singapore). Allergy / EpiPen rails: [kids allergy](/guides/kids-allergy-epipen-singapore). This guide is **asthma-flare coverage ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Flare triage is not dual “checking between meetings” |
| **Inhaler + spacer kit at home and school** | Device location beats memory at 02:00 |
| **GP vs A&E fork card** | Written red flags beat forum folklore |
| **PE / swim / outdoor hold** | Whistle days and pool decks wait |
| **Helper rest-day rewrite** | Flare Sundays are the wrong Sundays for surprise offs |

## Dual-career playbook

1. Put the written action plan + device locations in the shared family channel.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early if the flare is climbing ([finding a paediatrician](/guides/finding-pediatrician-singapore)).  
4. Pause PE, outdoor CCA, and swim until the written hold lifts ([kids swimming & water safety](/guides/kids-swimming-water-safety-singapore)).  
5. On haze days, stack this guide with [haze PSI coverage](/guides/dual-career-haze-psi-school-closure-coverage-singapore).  
6. Rewrite helper rest-day collisions if the flare lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| Both parents “monitoring between Zooms” | One coverage owner |
| Empty spacer in the school bag | Kit check the night before |
| Sending a wheezy child to outdoor PE “to toughen up” | Written activity hold |
| Treating every night cough as “just AC” | Follow the clinician action plan |
| Ignoring rest-day collisions | Rewrite early |
