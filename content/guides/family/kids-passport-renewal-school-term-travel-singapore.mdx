Kids’ passports expire on their own calendar. Schools, mocks, and DP card photos do not care. r/askSingapore parents keep discovering mid-term that airline “6 months validity” rules and embassy appointment queues are the real critical path — not the holiday brochure.

Leave and jet-lag ops: [home-leave jet lag](/guides/home-leave-jetlag-dual-career-family-singapore). Newborn first documents: [newborn pass](/guides/newborn-pass-birth-registration-singapore). This guide is **renewal + school-term travel timing**.

## Timing rules of thumb

| Constraint | Plan for |
| --- | --- |
| **Airline / destination validity** | Many carriers want ≥6 months on arrival — verify route rules |
| **Embassy / consulate slots** | Peak before long breaks; book months ahead for some nationalities |
| **School blackouts** | Mocks, exam weeks, compulsory camps — ask the calendar office |
| **DP / pass photos** | Passport renewals can force pass updates — check MOM/ICA sequencing |
| **Dual-national paperwork** | Two queues; start with the slower one |

<OfficialSource>
Entry/exit framing: [ICA](https://www.ica.gov.sg/). Dependant’s Pass overview: [MOM DP](https://www.mom.gov.sg/passes-and-permits/dependants-pass). Embassy renewal steps are **nationality-specific** — use your consulate’s live checklist, not a Facebook PDF.
</OfficialSource>

## School-term travel hygiene

1. Read the school’s **absence policy** before buying tickets — some IS programmes are strict on term-time leave.  
2. Avoid boarding/exam windows ([IB/A-Level pathways](/guides/secondary-ib-alevel-pathways-singapore)).  
3. Build a 48-hour buffer after return for fever/jet lag before high-stakes tests.  
4. If one parent travels with kids, name the on-island coverage adult ([sick-child coverage](/guides/dual-career-sick-child-coverage-singapore)).  
5. Holiday-camp logistics are a different product — [kids activities](/guides/kids-activities-holiday-camps).

## Dual-career ops

| Move | Why |
| --- | --- |
| Shared passport expiry sheet (all kids + both adults) | Surprises are usually month 5 |
| One adult owns embassy appointment logistics | Two “I’ll look at it” = none |
| Photo day after haircuts / braces adjustments | Rejected photos burn slots |
| Scan bio pages to a shared vault | Hotel Wi‑Fi is not your DMS |

## What this is not

- Not legal advice on custody-related travel consent  
- Not a substitute for your embassy’s appointment system  
- Not immigration advice on pass replacements after passport change — confirm with MOM/employer HR when the passport number changes

Dual-career note: weekday sports fixtures and academy lessons do not pause for embassy photo appointments — block the passport slot like a fixture kickoff and name one kit/documents owner ([sports-fixture ops](/guides/international-school-sports-fixture-weekday-ops-dual-career-singapore)).
