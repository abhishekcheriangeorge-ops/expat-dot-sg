Book week is not “just dress as a character”. Dual-career EP/DP households on r/askSingapore keep discovering that **costume blackouts, parade call times, and book-order PayNow** collide with client decks harder than Sports Day.

This guide is **book week / author-visit ops**.

## Ops products

| Product | Why |
| --- | --- |
| **Costume blackout night** | Same-day Shopee fails in the car park |
| **Parade / assembly call time** | Arrival is earlier than the newsletter headline |
| **Hard book-order / donation cap** | Fair bundles and signed copies stack quietly |
| **Named adult for the visit slot** | Dual muted Slack is not a seat |
| **Volunteer blackout vs helper rest day** | Class reader slots collide with Sundays |

## Dual-career playbook

1. Pull theme, call time, gate, book-order deadline, and volunteer asks the day the letter drops.  
2. Calendar a **costume blackout** and a named adult for the parade / author slot ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Set a hard wallet cap before book bundles and signed copies open.  
4. If volunteer slots land on a helper rest day, rewrite coverage early ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).  
5. Keep enrichment load capped the same week ([kids activities](/guides/kids-activities-holiday-camps)).

## Traps

| Trap | Fix |
| --- | --- |
| Reading only “Book Week Friday”, missing Thursday call | Calendar the call time |
| Both parents “hoping to catch the author Q&A” | One named hall adult |
| Unlimited PayNow for books / photos | Hard wallet cap |
| Sewing at 23:40 after a board deck | Costume blackout the night before |
| Stacking fair + book week + recital same fortnight | Cap one peak costume event |

## Questions to close this week

1. What is the exact call time and gate?  
2. Which adult owns the visit / parade seat?  
3. What is the hard book-order wallet cap?  
4. Does volunteer coverage collide with helper rest day?
