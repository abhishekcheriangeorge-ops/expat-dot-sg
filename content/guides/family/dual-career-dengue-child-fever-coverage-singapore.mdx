Cluster maps make every fever feel like dengue. Dual-career EP/DP households on r/askSingapore keep Googling platelet counts at 01:00 while both calendars are still full — then learning that “wait and see” still needs a **named daytime adult**.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). HFMD letters: [HFMD coverage](/guides/dual-career-hfmd-school-outbreak-coverage-singapore). Estate fogging: [dengue cluster living](/guides/dengue-cluster-living-renters). This guide is **child fever during dengue-season ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Fever + warning signs are not dual muted Slack |
| **GP timing plan** | Know when to go today vs monitor overnight |
| **Hydration / warning-sign card** | Written list beats memory at 03:00 |
| **Sibling outdoor freeze** | Parks and sidelines wait while the house is mid-fever |
| **Helper rest-day rewrite** | Cluster weeks are the wrong weeks for surprise Sundays |

## Dual-career playbook

1. Forward the estate cluster notice + school fever policy into the shared channel.  
2. Name today’s coverage owner before the first Zoom ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric slots early if warning signs appear ([finding a paediatrician](/guides/finding-pediatrician-singapore)).  
4. Pause CCA / academy / sideline commitments for the febrile child.  
5. Ward path if directed: [hospitalisation coverage](/guides/dual-career-child-hospitalisation-coverage-singapore).

## Traps

| Trap | Fix |
| --- | --- |
| Treating every fever as confirmed dengue | Clinical assessment first |
| Both parents “monitoring between meetings” | One coverage owner |
| Sending siblings to outdoor fixtures anyway | Freeze until the household plan is clear |
| Ignoring rest-day collisions | Rewrite ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)) |
