Birthday season in international-school cohorts is a **logistics sport**. Dual-career EP/DP households on r/askSingapore keep buying the soft-play package first and discovering condo by-laws, guest-list inflation, and helper rest days second.

Belonging can happen without a party industrial complex — [park playground belonging](/guides/park-playground-parent-belonging-singapore). This guide is **party ops**.

## Product choices (pick one primary)

| Format | Best when | Watch-outs |
| --- | --- | --- |
| **Playground / park picnic** | Younger kids; budget | Heat, haze, booking rules ([NParks](https://www.nparks.gov.sg/)) |
| **Condo function room** | Convenience | MCST deposits, end times, cooking bans |
| **Soft-play / activity venue** | Rain season | Lead times; sibling tags; sugar exits |
| **Club / association room** | Members already | Guest fees; proposer culture |
| **Home party** | Tiny guest list | Noise complaints; cleanup cliff |

<OfficialSource>
Park facility orientation: [NParks](https://www.nparks.gov.sg/). Private estates: **MCST by-laws** beat Facebook folklore for function rooms and quiet hours.
</OfficialSource>

## Dual-career runbook (T−21 to T+1)

| When | Move |
| --- | --- |
| T−21 | Venue hold + calendar block for **both** adults |
| T−14 | Guest list cap; send invites with end time |
| T−7 | Food, bags, helper/sitter plan; rest-day check |
| T−2 | Confirm headcount; pack activity kit / wet wipes |
| Day | One adult “host ops,” one adult “kid safety” |
| T+1 | Deposit reclaim photos; thank-yous; no new party bookings for 30 days |

## Hygiene rules

1. Cap guests before class-group pressure expands the list.  
2. Do not use the party as unpaid childcare for cousins of friends.  
3. Keep a fever cancel policy in the invite ([sick-child coverage](/guides/dual-career-sick-child-coverage-singapore)).  
4. Helper bandwidth is not infinite — write tasks ([hiring MDW](/guides/hiring-domestic-helper-mdw)).  
5. Weekday parties need school pickup maths — treat like a meeting ([dual-career spouse](/guides/dual-career-spouse-singapore)).

Condo guest politics: [condo parent networks](/guides/condo-block-parent-networks-belonging-singapore).
