PTC week is not a courtesy coffee. For dual-career EP/DP households it is a **decision meeting** squeezed between standups — and r/askSingapore parents keep showing up unprepared, sending the wrong adult, or leaving without a written next step.

School choice context: [landscape](/guides/international-schools-landscape). Support vs tutoring: [learning support vs tutoring](/guides/international-school-learning-support-vs-tutoring-singapore). This guide is **PTC ops**.

## Before the slot

| Prep | Why |
| --- | --- |
| Book early; put both calendars on hold | Popular teachers vanish by lunch |
| Decide **lead parent** + silent note-taker | Two talkers = no notes |
| One-page concern list (max 3) | Wandering chats waste the 15 minutes |
| Bring samples / screenshots if digital learning is the issue | Anecdotes lose to artefacts |
| Ask if learning-support lead should join | Don’t discover mid-meeting that you needed them |

<OfficialSource>
Parent partnership orientation: [MOE Parent Hub](https://www.moe.gov.sg/parent-hub). International-school conference formats vary — ask the school’s written PTC guide ([MOE international schools](https://www.moe.gov.sg/international-schools)).
</OfficialSource>

## In the room (or Zoom)

1. Start with what is working — 30 seconds — then your top concern.  
2. Ask: “What should **home** stop / start this fortnight?”  
3. Ask: “What will **school** change, and who owns it?”  
4. Capture names, dates, and the follow-up channel (email vs platform).  
5. If SEN / ADHD / language support is in play, schedule a second meeting — do not smuggle it into leftover minutes ([special needs](/guides/special-needs-support)).

## Dual-career rules

| Rule | Reason |
| --- | --- |
| One adult may attend if briefed; both should not improvisationally tag-team | Coherence |
| Travel weeks: send a written brief to the attending parent 24h ahead | Avoid “you handle it” |
| Same-day action note in the family shared doc | Memory is not a system |
| No new tutor hired from the car park without a stop date | Invoice hygiene |

## Aftercare

- Email a three-bullet recap to the teacher if anything was ambiguous.  
- Update the sick-day / travel matrices if the plan changes pickup load.  
- University-track families: keep PTC notes for later counselling narratives ([university counselling](/guides/university-counselling-international-schools-singapore)).

Book-week and author-visit weeks need their own call-time and wallet-cap products — do not treat them as another PTC slot ([book week / author-visit ops](/guides/international-school-book-week-author-visit-ops-dual-career-singapore)).
