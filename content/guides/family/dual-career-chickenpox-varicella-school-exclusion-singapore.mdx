Chickenpox is not “a light fever day.” Dual-career EP/DP households on r/askSingapore keep underestimating **crusting rules**, sibling cascade, and centres that want a written clearance before return.

HFMD playbook: [HFMD / outbreak coverage](/guides/dual-career-hfmd-school-outbreak-coverage-singapore). Ordinary fever: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). This guide is **varicella / chickenpox exclusion**.

## Exclusion products

| Product | Why |
| --- | --- |
| **Crusting clock** | Return rules usually track lesions, not parental optimism |
| **Sibling plan** | Exposed siblings may still attend — or not — centre-specific |
| **GP letter habit** | Screenshot the centre’s ask before the visit |
| **Named daytime adult** | One calendar owner per day; not dual “flex” folklore |
| **Visitor freeze** | Cousin playdates turn one case into three |

<OfficialSource>
Clinical orientation: [HealthHub chickenpox](https://www.healthhub.sg/a-z/diseases-and-conditions/chickenpox) and [MOH](https://www.moh.gov.sg/). Centre exclusion and clearance letters are operator-specific — read the letter ([ECDA](https://www.ecda.gov.sg/) sector orientation for early childhood). Vaccination history for foreign kids: start from [childhood vaccination](/guides/childhood-vaccination-foreigners), not forum dose folklore.

## Dual-career playbook

1. Forward the centre letter into the shared channel within 15 minutes.  
2. Lock the expected return window as a calendar event with the child’s initials.  
3. Pre-book the clearance visit; do not queue at 08:00 on day-of.  
4. Keep enrichment / sports-day rehearsals cancelled until written clearance.  
5. Role map: [dual-career spouse](/guides/dual-career-spouse-singapore). Backup: [sitters](/guides/part-time-babysitter-nanny-singapore).

## Traps

| Trap | Fix |
| --- | --- |
| “Spots look dry to me” | Follow the centre’s written crusting / clearance rule |
| Sending a well sibling into a closed class | Confirm status daily |
| Burning both parents’ PTO on day one | Stagger coverage |
| Ignoring itch / sleep debt | Sick matrix still applies |
