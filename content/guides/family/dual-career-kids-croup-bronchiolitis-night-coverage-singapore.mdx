Barky night cough is not a dual-muted Slack problem. Dual-career EP/DP households on r/askSingapore keep debating “steam vs ED” at 02:10 — then learning that **named overnight owners, written return clocks, and GP/ED forks** beat forum folklore.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Asthma flares: [asthma-flare coverage](/guides/dual-career-kids-asthma-flare-coverage-singapore). Ear nights: [ear-infection / ENT](/guides/dual-career-kids-ear-infection-ent-coverage-singapore). This guide is **croup / bronchiolitis night coverage**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named overnight adult** | 02:00 breathing checks are not dual “later” |
| **GP / ED fork** | Know red-flag lines before the night escalates |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Day-after deep-work shield** | Non-coverage parent needs one protected block |
| **Helper rest-day rewrite** | Night coverage often lands on Sunday collisions |

<OfficialSource>
Clinical orientation: [NHS bronchiolitis](https://www.nhs.uk/conditions/bronchiolitis/) and [NHS croup](https://www.nhs.uk/conditions/croup/), plus [MOH](https://www.moh.gov.sg/). Early-childhood sector orientation: [ECDA](https://www.ecda.gov.sg/). Exclusion and return windows are **operator-specific** — follow the letter and the clinician plan.
</OfficialSource>

## Dual-career playbook

1. Photograph the school / centre return rule into the shared channel within 15 minutes of the letter or GP note.  
2. Name tonight’s coverage owner before bedtime ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Write the GP vs ED fork with red flags; do not invent steam folklore ([finding a paediatrician](/guides/finding-pediatrician-singapore)).  
4. Put the return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause swim / vigorous PE until the hold lifts if the letter requires it.  
6. Rewrite helper rest-day collisions early ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| Both parents “monitoring” between Zooms | One overnight owner |
| “Steam fixed it” without a clinician plan | Follow GP / ED guidance |
| Sending a still-wheezy child to centre | Written return clock |
| No day-after shield for the night owner | Calendar a recovery block |
| Ignoring Sunday helper rest-day stack | Rewrite coverage early |
