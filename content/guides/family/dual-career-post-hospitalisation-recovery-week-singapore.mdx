Discharge is not “back to normal.” Dual-career EP/DP households on r/askSingapore keep treating day-one-home like a regular WFH Tuesday — then rediscover sleep debt, wound care, sibling jealousy, and a piling site next door.

Ward week: [child hospitalisation coverage](/guides/dual-career-child-hospitalisation-coverage-singapore). Sibling cascade: [sibling care during hospitalisation](/guides/dual-career-sibling-care-during-hospitalisation-singapore). This guide is **recovery week**.

## Recovery-week products

| Need | Plan |
| --- | --- |
| **Named daytime adult** | Not “both flex” — one calendar owner per day |
| **Quiet sleep window** | Negotiate construction / renovation awareness; relocate bedroom if needed |
| **School / preschool re-entry** | Written clearance rules; partial days beat heroic full days |
| **Follow-up clinics** | Book before discharge; stack with one parent’s meeting blackouts |
| **Sibling bandwidth** | Keep enrichment cancelled 3–5 days |

<OfficialSource>
Clinical follow-up is hospital/clinic-specific ([MOH system orientation](https://www.moh.gov.sg/home/our-healthcare-system)). Estate noise escalation paths differ for HDB vs condo — start with town council / MCST channels, not only neighbour WhatsApp.
</OfficialSource>

## Housing friction that breaks recoveries

| Friction | Move |
| --- | --- |
| Piling / renovation next door | Temporary room swap; document dates ([construction noise](/guides/construction-site-noise-renters)) |
| Mould / damp bedroom | Do not convalesce there ([mould/humidity](/guides/mould-humidity-rental-tenants)) |
| Helper rest day on day-two home | Shift rest day before discharge |
| Visitor pile-on | Cap visitors; protect naps |

## Dual-career rules

1. Keep the **ward-parent / home-parent** labels for 72 hours post-discharge.  
2. Put clinic follow-ups on both work calendars as hard holds.  
3. Fever return path stays on the [sick-child matrix](/guides/dual-career-sick-child-coverage-singapore).  
4. One grocery / laundry deputy — recovery weeks fail on errands.  
5. Role clarity: [dual-career spouse](/guides/dual-career-spouse-singapore).
