Ordinary fever coverage is not an **outbreak letter**. Dual-career EP/DP households on r/askSingapore keep learning the hard way that HFMD (and sibling class closures) wipe **both** calendars for days — not one WFH Tuesday.

Baseline sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Ward path: [hospitalisation](/guides/dual-career-child-hospitalisation-coverage-singapore). This guide is **HFMD / outbreak ops**.

## Outbreak products (write these down)

| Product | Why |
| --- | --- |
| **Exclusion clock** | Centres follow fever-free / blister rules — hero returns bounce kids back out |
| **Sibling cascade plan** | One confirmed case can still strand a well sibling if the centre closes a class |
| **Named daytime adult** | Not “both flex” — one owner per day on the shared calendar |
| **GP letter habit** | Some centres demand written clearance; screenshot the ask before the visit |
| **Helper rest-day shift** | Outbreak week is the wrong week for a Sunday-only backup |

Clinical orientation: [MOH HFMD](https://www.moh.gov.sg/diseases-updates/hand-foot-and-mouth-disease) and [HealthHub HFMD](https://www.healthhub.sg/a-z/diseases-and-conditions/hand-foot-and-mouth-disease). Centre exclusion and class-closure rules are operator-specific — read the letter, do not invent folklore. Early-childhood sector orientation: [ECDA](https://www.ecda.gov.sg/).

## Dual-career playbook

1. Forward the centre letter into the shared family channel **within 15 minutes**.  
2. Lock the exclusion end-date as a calendar event titled with the child’s initials.  
3. Pre-book the GP / paediatric slot for clearance day — do not wait until 08:00 that morning.  
4. Cap visitors and playdates; HFMD weeks fail on “just one cousin”.  
5. Keep enrichment and sports-day rehearsals cancelled until clearance is written.  
6. Role clarity: [dual-career spouse](/guides/dual-career-spouse-singapore). Backup adults: [part-time sitters](/guides/part-time-babysitter-nanny-singapore).

## What not to do

| Trap | Fix |
| --- | --- |
| Treating rash-free mornings as “cleared” | Follow the centre’s written rule, not WhatsApp folklore |
| Sending a well sibling into a closed class | Confirm class status daily |
| Burning both parents’ PTO on day one | Stagger coverage; protect one deep-work block |
| Ignoring hydration / pain while chasing meetings | Sick matrix still applies |

Preschool context: [preschool & childcare](/guides/preschool-childcare-singapore). Clinical continuity: [finding a paediatrician](/guides/finding-pediatrician-singapore).

Pink-eye weeks need the same **written return rule** discipline — sticky eyes are not a vibes clearance ([conjunctivitis / pink-eye exclusion](/guides/dual-career-kids-conjunctivitis-pink-eye-school-exclusion-singapore)).
