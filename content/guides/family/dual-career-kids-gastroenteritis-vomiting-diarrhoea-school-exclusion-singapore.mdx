One vomit in the classroom and the dual-career week collapses. EP/DP households on r/askSingapore keep arguing “48 hours symptom-free” folklore at 06:40 while both Slack statuses stay green — then learning that **return rules are written**, not vibes.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Rash outbreaks: [HFMD coverage](/guides/dual-career-hfmd-school-outbreak-coverage-singapore). Vesicles: [chickenpox exclusion](/guides/dual-career-chickenpox-varicella-school-exclusion-singapore). This guide is **gastro / vomiting–diarrhoea exclusion ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named overnight + morning owner** | Vomiting peaks before first stand-up |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Hydration / red-flag card** | Written list beats memory at 03:00 |
| **Swim / food-handling hold** | Pool and cooking CCA are not “fresh air” |
| **Sibling cascade check** | Same bathroom can wipe both calendars |

## Dual-career playbook

1. Photograph the school/preschool exclusion text into the shared channel within 15 minutes.  
2. Name today’s coverage owner before the first Zoom ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review if red flags appear ([finding a paediatrician](/guides/finding-pediatrician-singapore)); do not invent forum ORS recipes as medical advice.  
4. Put the symptom-free return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause swim and food-related enrichment until the written hold lifts ([kids swimming & water safety](/guides/kids-swimming-water-safety-singapore)).  
6. Rewrite helper rest-day collisions if exclusion lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| “No vomit since breakfast” = cleared | Follow the written return clock |
| Both parents “monitoring between meetings” | One coverage owner |
| Sending a still-queasy child to swim “for the social” | Written water hold |
| Sharing cups / towels across siblings | Laundry + separate cups day one |
| Burning both PTO stacks on day one | Stagger coverage |

## Questions to close tonight

1. Who owns overnight hydration checks?  
2. What exact line does the school letter use for return?  
3. Is swim / food CCA paused in writing?  
4. Does the well sibling’s class still run tomorrow?
