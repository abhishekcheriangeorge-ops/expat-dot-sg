Winter fair is not book fair with fairy lights. Dual-career parents on r/askSingapore keep underestimating **stall shift lengths**, class baking deadlines, and the way a “two-hour volunteer” eats an entire work afternoon.

Book fair: [book-fair ops](/guides/international-school-book-fair-fundraising-ops-dual-career-singapore). Sports day: [sports-day ops](/guides/international-school-sports-day-carnival-ops-dual-career-singapore). This guide is **winter fair / bazaar ops**.

## Ops checklist

| When | Move |
| --- | --- |
| T−21 | Read stall / shift / cash vs PayNow rules |
| T−14 | Set a **hard wallet cap** per child; decline third raffle books |
| T−7 | One named volunteer; put a work blackout on that block |
| T−2 | Baking / craft deadlines — buy if sleep debt is real |
| Day | Sibling care plan; heat/haze backup if outdoor |
| After | Lost-property sweep; thank-you only if bandwidth remains |

<OfficialSource>
Fair formats and volunteer rules are school-specific ([MOE international schools](https://www.moe.gov.sg/international-schools); [Parent Hub](https://www.moe.gov.sg/parent-hub)). Do not invent “all IS bazaars are Sunday mornings” folklore.
</OfficialSource>

## Dual-career traps

1. **Both parents RSVP maybe** — one named shift beats two ghosts.  
2. **Open-ended PayNow** — pre-load a cap.  
3. **Helper rest day on fair Sunday** — rewrite early ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).  
4. **PH week stacking** — fair + public holiday coverage needs separate owners ([PH coverage](/guides/dual-career-public-holiday-school-closed-coverage-singapore)).  
5. Role map: [dual-career spouse](/guides/dual-career-spouse-singapore).
