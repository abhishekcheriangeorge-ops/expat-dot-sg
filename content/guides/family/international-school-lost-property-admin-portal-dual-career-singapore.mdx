Lost-property chaos is a **labelling + portal** problem. Dual-career parents on r/askSingapore keep rediscovering the same water bottle in the bin, missing permission-slip deadlines, and arguing about who owns the school app notifications.

Bus ops: [bus/pickup](/guides/international-school-bus-pickup-dual-career-singapore). This guide is **lost property + admin portal ops**.

## Ops checklist

| Habit | Move |
| --- | --- |
| Label everything | Name + class + phone on bottles, lunchboxes, PE kits |
| Weekly lost-property sweep | One named adult; same weekday |
| Portal notification owner | One phone gets critical alerts unmuted |
| Permission-slip SLA | 24-hour rule: open → decide → submit |
| Spare kit at home | One labelled backup uniform / bottle |

<OfficialSource>
Portal workflows and lost-property policies are school-specific ([MOE international schools](https://www.moe.gov.sg/international-schools); [Parent Hub](https://www.moe.gov.sg/parent-hub)). Do not invent “the office always keeps it for a term” folklore.
</OfficialSource>

## Dual-career traps

1. **Both parents muted** — one named notification owner.  
2. **Buying replacements instead of sweeping** — check the bin before Shopee.  
3. **Permission slips in a kids’ backpack photo dump** — screenshot to the shared channel.  
4. **Teen “I’ll handle the portal”** — verify submission status ([teen phone/household](/guides/teen-phone-social-media-household-singapore)).  
5. Role map: [dual-career spouse](/guides/dual-career-spouse-singapore).
