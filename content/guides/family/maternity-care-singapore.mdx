Maternity is where insurance fine print becomes biography. On r/askSingapore, the recurring failure mode is discovering a pregnancy **after** a basic corporate plan excluded maternity — then shopping for cover that underwriters will not write.

## Before you conceive (if you can plan)

| Check | Why |
| --- | --- |
| Employer plan maternity inclusion | Many group plans exclude it entirely |
| Waiting periods | Often 10–12 months on private add-ons |
| Delivery package scope | What complications are out-of-package? |
| Neonatal / NICU cover | Premature births are the balance-sheet event |
| Dependants’ outpatient | Postpartum GP load is real |

If you are already pregnant, assume **cash-pay planning** for delivery at your chosen hospital tier plus whatever residual group cover exists. See [health insurance for expats](/guides/health-insurance-expat).

## Care pathway choices

| Path | Upside | Trade-off |
| --- | --- | --- |
| Private OB + private hospital package | Continuity, English-heavy experience, scheduling | High absolute cost; packages ≠ unlimited complications |
| Public hospital as foreigner | Excellent clinical reputation | Typically **unsubsidised / private-patient** billing — not the citizen subsidy story |

Peer anecdotes about caesarean packages at private hospitals are useful for **order-of-magnitude** planning only — get live quotes from the hospital and your insurer.

## Cost realism themes (not quotes)

- Uncomplicated private delivery packages already sit in **five-figure SGD** territory historically, before NICU  
- NICU days can dwarf the delivery package  
- Helper / night nurse / relative flights are the soft costs packages ignore  

## After birth — admin is a project

Budget calendar time, not just money:

1. Birth registration  
2. Passport application (home country rules)  
3. Dependant’s Pass / LTVP pathway for the newborn — see [Dependant Pass](/guides/dependant-pass-singapore)  
4. Insurance enrolment for the baby (day-0 myths vs real underwriting)  
5. Housing / helper capacity for the fourth trimester — see [MDW hiring](/guides/hiring-domestic-helper-mdw)  

## Practical sequence for arriving couples

1. Audit employer maternity language **before** resigning elsewhere  
2. If trying to conceive in year one, buy appropriate cover **before** you need it  
3. Shortlist OB/hospital with insurance panels in mind  
4. Parallel-path childcare plan (helper and/or infant care waitlists)
