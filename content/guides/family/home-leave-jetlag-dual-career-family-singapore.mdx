Home leave is the reward. **The Monday after** is the bill. Dual-career EP/DP threads on r/askSingapore keep describing the same crash: kids still on origin-country clocks, one adult on a 9am standup, and a helper rest day that lands on the worst morning.

Holiday camps are a different season — [kids activities](/guides/kids-activities-holiday-camps). This guide is **leave + jet-lag household ops**.

## Plan the return before you book the outbound

| Decision | Do this before tickets | Why |
| --- | --- | --- |
| **Re-entry week owner** | Name one adult “on call” for days 1–3 back | Two jet-lagged EPs = zero coverage |
| **School / preschool notice** | Email absence + first full day back | Late notes create admin debt |
| **Helper / sitter calendar** | Align rest days away from return Monday | Rest-day cliffs are predictable |
| **Sleep shift** | Start sliding bedtime 2–3 days before flight home | Better than heroic first-night resets |
| **Meeting blackout** | Block AM meetings day 1–2 back | Your calendar will not do this for you |

## Jet-lag ops that actually work in SG humidity

1. **Light + meal timing** beat melatonin folklore for most school-age kids — ask a clinician before any sleep meds.  
2. Keep **one familiar breakfast** the first two mornings back.  
3. Cut new enrichment for the return week — tutoring catch-up can wait ([learning support vs tutoring](/guides/international-school-learning-support-vs-tutoring-singapore)).  
4. Younger kids: expect fever/sniffles after flights; know your GP path.  
5. Neighbourhood commute length amplifies morning pain — housing still matters ([choosing a neighbourhood](/guides/choosing-neighbourhood-expat)).

## Dual-career failure modes

| Failure | Fix |
| --- | --- |
| Both adults “work from home to ease in” while on calls | One adult is coverage; the other is work — label it |
| Home leave overlaps exam week | Do not — or pre-assign quiet-house rules before you fly |
| Vaccination / checkup deferred “until after leave” | Book before outbound when possible ([childhood vaccination](/guides/childhood-vaccination-foreigners)) |
| Preschool exclusion on day two | Backup adult named in writing |

## A one-page return checklist

- [ ] First full school day date shared with both employers  
- [ ] Helper rest day not on return Monday  
- [ ] Grab / sitter overflow budget for mornings 1–3  
- [ ] Devices back on Singapore bedtime the night before school  
- [ ] No new tutor starts in the return week
