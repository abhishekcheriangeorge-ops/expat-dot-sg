Fever plus raw throat is not a dual-muted Slack problem. Dual-career EP/DP households on r/askSingapore keep debating “viral vs strep” at 06:10 — then learning that **written return clocks and named coverage owners** beat forum antibiotic folklore.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Skin exclusions: [impetigo](/guides/dual-career-kids-impetigo-school-exclusion-singapore). Gut bugs: [gastro exclusion](/guides/dual-career-kids-gastroenteritis-vomiting-diarrhoea-school-exclusion-singapore). This guide is **strep-throat exclusion ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Swabs and fever checks are not dual “later” |
| **GP / swab timing plan** | Know when pharmacy lozenges fail |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Sibling sharing freeze** | Cups, towels, and toothbrushes cascade |
| **Swim / choir / wind-instrument hold** | Shared saliva spaces wait |

## Dual-career playbook

1. Photograph the school exclusion / return rule into the shared channel within 15 minutes.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early ([finding a paediatrician](/guides/finding-pediatrician-singapore)); do not invent forum rapid-test folklore.  
4. Put the written return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause swim, choir, and shared mouthpieces until the hold lifts ([kids swimming & water safety](/guides/kids-swimming-water-safety-singapore)).  
6. Rewrite helper rest-day collisions if exclusion lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
