Burning wees and fever are not a dual-muted Slack problem. Dual-career EP/DP households on r/askSingapore keep debating “wait overnight vs GP now” at 06:20 — then learning that **named coverage owners, antibiotic plans, and written return clocks** beat forum folklore.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Night respiratory weeks: [croup/bronchiolitis night coverage](/guides/dual-career-kids-croup-bronchiolitis-night-coverage-singapore). Ear nights: [ear-infection / ENT](/guides/dual-career-kids-ear-infection-ent-coverage-singapore). This guide is **UTI school-return coverage**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Sample runs and fever checks are not dual “later” |
| **GP timing plan** | Know when pharmacy folklore fails |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Antibiotic realism** | Finish the clinician plan; do not invent “cleared after dose one” |
| **Swim / PE hold** | Shared water and long sits wait |

## Dual-career playbook

1. Photograph the school / centre return rule into the shared channel within 15 minutes.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early ([finding a paediatrician](/guides/finding-pediatrician-singapore)); do not invent forum antibiotic folklore.  
4. Put the written return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause swim and long PE sits until the hold lifts ([kids swimming & water safety](/guides/kids-swimming-water-safety-singapore)).  
6. Rewrite helper rest-day collisions if coverage lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| “Fever broke after breakfast” = cleared | Follow the written return clock |
| Both parents monitoring between Zooms | One coverage owner |
| Stopping antibiotics early for school | Finish the clinician plan |
| Sending a still-symptomatic child to swim | Written activity hold |
| Ignoring hydration / toilet access plans | Pack and brief the centre |
