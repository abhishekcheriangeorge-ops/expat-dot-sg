Photo day is a tiny calendar line that creates outsized dual-career pain: missing ties, fever cancellations, and retake fees. r/askSingapore parents keep learning that the school circular’s **order deadline** is the real critical path — not the smile.

Pickup ops: [IS bus & pickup](/guides/international-school-bus-pickup-dual-career-singapore). This guide is **photo-day ops**.

## Pre-flight checklist (T−7)

| Item | Owner |
| --- | --- |
| Circular read + order form submitted | Named adult |
| Uniform pieces washed / labelled | Home ops |
| Haircut buffer (optional) | Book before, not morning-of |
| Sibling shot opt-in | Decide once; don’t renegotiate at drop-off |
| Fever plan | If sick, follow [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore) + retake rules |

<OfficialSource>
School photo vendors and retake policies are **school-specific**. Use the live circular; Parent Hub orientation: [MOE Parent Hub](https://www.moe.gov.sg/parent-hub). International-school framing: [MOE international schools](https://www.moe.gov.sg/international-schools).
</OfficialSource>

## Morning-of dual-career rules

1. One adult owns wardrobe QA — the other owns commute.  
2. No new enrichment experiments that morning.  
3. If the bus is the plan, build a 15-minute smile buffer.  
4. Digital proof / sibling composites: note the **payment cut-off** in the shared calendar.  
5. Travel weeks: brief the attending parent like a PTC ([PTC ops](/guides/parent-teacher-conference-dual-career-singapore)).

## Failure modes

| Failure | Fix |
| --- | --- |
| Order form left in the school bag | Submit online the night the circular lands |
| PE kit worn instead of formal | Lay out clothes at T−1 evening |
| Sibling shot missed because of staggered campuses | Ask vendor/school for multi-campus rules early |
| Retake forgotten after fever | Put retake date on both work calendars |
