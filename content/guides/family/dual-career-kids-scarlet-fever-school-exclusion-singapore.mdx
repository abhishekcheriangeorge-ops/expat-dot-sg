Sandpaper rash plus fever is not a dual-muted Slack problem. Dual-career EP/DP households on r/askSingapore keep debating “viral rash vs scarlet fever” at 05:50 — then learning that **written return clocks, antibiotic plans, and named coverage owners** beat forum folklore.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Throat bugs without the rash map: [strep exclusion](/guides/dual-career-kids-strep-throat-school-exclusion-singapore). Skin exclusions: [impetigo](/guides/dual-career-kids-impetigo-school-exclusion-singapore) and [ringworm/tinea](/guides/dual-career-kids-ringworm-tinea-school-exclusion-singapore). This guide is **scarlet fever exclusion ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Rash checks and fever curves are not dual “later” |
| **GP timing plan** | Know when sandpaper rash + sore throat needs a letter |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Antibiotic realism** | Finish the clinician plan; do not invent “cleared after dose one” |
| **Sibling cascade freeze** | Shared cups, towels, and toothbrushes cascade |

## Dual-career playbook

1. Photograph the school exclusion / return rule into the shared channel within 15 minutes.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early ([finding a paediatrician](/guides/finding-pediatrician-singapore)); do not invent forum rapid-test folklore.  
4. Put the written return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause choir, wind instruments, and shared mouthpieces until the hold lifts.  
6. Rewrite helper rest-day collisions if exclusion lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| “Fever broke after breakfast” = cleared | Follow the written return clock |
| Both parents monitoring between Zooms | One coverage owner |
| Stopping antibiotics early for school | Finish the clinician plan |
| Sharing cups / toothbrushes | Sibling freeze day one |
| Treating every rash as scarlet fever folklore | Clinician diagnosis + school letter |
