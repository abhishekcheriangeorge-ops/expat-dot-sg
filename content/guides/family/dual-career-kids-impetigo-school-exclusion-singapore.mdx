Honey-coloured crusts travel faster than Slack replies. Dual-career EP/DP households on r/askSingapore keep debating “just a mosquito bite” at bus time — then learning that **school exclusion and return rules are written**, not vibes.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Rash outbreaks: [HFMD coverage](/guides/dual-career-hfmd-school-outbreak-coverage-singapore). Vesicles: [chickenpox exclusion](/guides/dual-career-chickenpox-varicella-school-exclusion-singapore). Gut bugs: [gastro exclusion](/guides/dual-career-kids-gastroenteritis-vomiting-diarrhoea-school-exclusion-singapore). This guide is **impetigo exclusion ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Dressing changes and GP slots are not dual muted Slack |
| **Written return rule** | Centre letters beat WhatsApp folklore |
| **GP / culture fork** | Know when pharmacy cream folklore fails |
| **Swim / contact-sport hold** | Pool decks and judo mats do not want open sores |
| **Towel / laundry reset** | Shared face towels cascade siblings |

## Dual-career playbook

1. Photograph lesions once for the GP chat — then wash hands and stop sharing towels.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early ([finding a paediatrician](/guides/finding-pediatrician-singapore)).  
4. Forward the school/preschool exclusion + return rule into the shared channel; calendar the clearance date.  
5. Pause swim and contact sports until the written hold lifts ([kids swimming & water safety](/guides/kids-swimming-water-safety-singapore)).  
6. Reset laundry and sibling towel rules the same day.

## Traps

| Trap | Fix |
| --- | --- |
| “Crust looks dry after breakfast” = cleared | Follow the written return rule |
| Both parents “monitoring between meetings” | One coverage owner |
| Sending open sores to swim “for the social” | Written water / mat hold |
| Sharing face towels and pillows | Laundry + separate towels day one |
| Stopping antibiotics early because school wants them back | Finish the clinician plan |

## Questions to close tonight

1. Who owns daytime dressing changes and GP follow-up?  
2. What exact line does the school letter use for return?  
3. Is swim / contact sport paused in writing?  
4. Are sibling towels separated?
