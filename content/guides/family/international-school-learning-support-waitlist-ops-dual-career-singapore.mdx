A learning-support referral is not a seat. Dual-career EP/DP households on r/askSingapore keep buying emergency tutors the night after the meeting — then discovering the school waitlist still needs a **named chase owner**, written interim goals, and a calendar for the next review.

Support vs tutoring decision: [LS vs tutoring](/guides/international-school-learning-support-vs-tutoring-singapore). Broader SEN: [special needs](/guides/special-needs-support). This guide is **LS waitlist ops**.

## Waitlist products

| Product | Why |
| --- | --- |
| **Written referral date** | Screenshots beat memory when staff rotate |
| **Named chase owner** | One adult owns portal / LS email follow-ups |
| **Interim goal sheet** | 2–3 classroom strategies while waiting — not ten new tutors |
| **Review meeting blackout** | Dual calendars fail when both parents “might join” |
| **Tutor spend cap** | Interim help with an end date, not a lifestyle |

<OfficialSource>
SEN system orientation: [MOE SEN](https://www.moe.gov.sg/special-educational-needs). International-school LS programmes are school-specific ([international schools](https://www.moe.gov.sg/international-schools); [Parent Hub](https://www.moe.gov.sg/parent-hub)) — do not invent “every IS guarantees pull-out within two weeks” folklore.
</OfficialSource>

## Dual-career playbook

1. File the referral packet the same week — psych reports, work samples, teacher notes.  
2. Put the expected review window on **both** work calendars ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Cap interim tutoring to goals that match the referral, not exam panic.  
4. Bring one clarifying question to PTC / progress meetings ([PTC](/guides/parent-teacher-conference-dual-career-singapore); [report cards](/guides/international-school-report-card-progress-meeting-dual-career-singapore)).  
5. If ADHD meds / clinical rails apply, keep them separate from homework rescue ([ADHD meds](/guides/kids-adhd-medication-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| Treating waitlist silence as “denied” | Chase with date-stamped emails |
| Stacking three tutors “just until LS starts” | One interim rail + end date |
| Both parents muted on the LS thread | One notification owner |
| Confusing school waitlists with LS waitlists | Different products ([school waitlist realism](/guides/school-waitlist-realism)) |
