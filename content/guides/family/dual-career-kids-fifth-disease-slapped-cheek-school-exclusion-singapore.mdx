Bright red cheeks are not a dual-muted Slack problem. Dual-career EP/DP households on r/askSingapore keep debating “sunburn vs slapped cheek” at 06:00 — then learning that **written return clocks, pregnancy-exposure notes, and named coverage owners** beat forum folklore.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Scarlet fever: [scarlet-fever exclusion](/guides/dual-career-kids-scarlet-fever-school-exclusion-singapore). Throat bugs: [strep exclusion](/guides/dual-career-kids-strep-throat-school-exclusion-singapore). This guide is **fifth disease / slapped-cheek exclusion ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Rash checks and fever curves are not dual “later” |
| **GP timing plan** | Know when slapped cheek needs a letter vs watchful waiting |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Pregnancy-exposure note** | Household and class contacts may need clinician advice |
| **Sibling cascade freeze** | Shared cups, towels, and close play cascade |

<OfficialSource>
Clinical orientation: [NHS slapped cheek syndrome](https://www.nhs.uk/conditions/slapped-cheek-syndrome/) and [MOH](https://www.moh.gov.sg/). Early-childhood sector orientation: [ECDA](https://www.ecda.gov.sg/). Exclusion windows are **operator-specific** — follow the letter and the clinician plan.
</OfficialSource>

## Dual-career playbook

1. Photograph the school exclusion / return rule into the shared channel within 15 minutes.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early if fever persists or pregnancy exposure is in play ([finding a paediatrician](/guides/finding-pediatrician-singapore)).  
4. Put the written return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause shared sports kit and close playdates until the hold lifts.  
6. Rewrite helper rest-day collisions if exclusion lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| “Cheeks look better after breakfast” = cleared | Follow the written return clock |
| Both parents monitoring between Zooms | One coverage owner |
| Ignoring pregnancy exposure in the household / class | Clinician + school letter, not folklore |
| Sharing cups / towels | Sibling freeze day one |
| Treating every red cheek as sunburn | Clinician diagnosis when fever or lace rash appears |

## Questions to close tonight

1. Who owns daytime fever / rash checks and GP follow-up?  
2. What exact line does the school letter use for return?  
3. Is any pregnancy exposure note required?  
4. Are sibling cups and towels separated?
