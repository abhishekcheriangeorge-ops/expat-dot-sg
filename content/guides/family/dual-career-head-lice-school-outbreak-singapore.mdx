A lice letter is not a fever day and not HFMD. Dual-career EP/DP households on r/askSingapore keep treating it like optional homework — then discovering pharmacy queues, pillowcase laundry, and a centre that wants proof of treatment before Monday.

HFMD: [HFMD coverage](/guides/dual-career-hfmd-school-outbreak-coverage-singapore). Chickenpox: [varicella exclusion](/guides/dual-career-chickenpox-varicella-school-exclusion-singapore). Ordinary sick: [sick-child](/guides/dual-career-sick-child-coverage-singapore). This guide is **head-lice outbreak ops**.

## Outbreak products

| Product | Why |
| --- | --- |
| **Same-day treatment owner** | One adult runs pharmacy + application — not dual “later tonight” |
| **Sibling check** | Assume household spread until combed clear |
| **Laundry / heat plan** | Pillowcases, hats, soft toys — helper rest days still happen |
| **School return rule** | Follow the letter; do not invent “nit-free certificate” folklore |
| **Class message discipline** | No public shaming in the parent chat |

Clinical orientation: [HealthHub head lice](https://www.healthhub.sg/a-z/diseases-and-conditions/head-lice) and [MOH](https://www.moh.gov.sg/). Centre exclusion / return rules are operator-specific ([ECDA](https://www.ecda.gov.sg/) for early childhood) — read the letter.

## Dual-career playbook

1. Forward the letter into the shared channel within 15 minutes.  
2. Name tonight’s treatment owner; put pharmacy on the way home.  
3. Check every sibling the same evening.  
4. Align helper tasks with laundry load — or shift rest day ([helper rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).  
5. Role map: [dual-career spouse](/guides/dual-career-spouse-singapore).

## Traps

| Trap | Fix |
| --- | --- |
| Waiting for weekend | Same-day treatment beats Monday escalation |
| Treating only the named child | Comb the household |
| Public blame in WhatsApp | Private ops only |
| Skipping re-check | Follow product / clinic intervals |
