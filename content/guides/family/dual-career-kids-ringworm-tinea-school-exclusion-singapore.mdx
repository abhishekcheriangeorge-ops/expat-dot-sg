Itchy round patches are not a dual-muted Slack problem. Dual-career EP/DP households on r/askSingapore keep debating “is it eczema or ringworm?” at 06:05 — then learning that **written return clocks, kit freezes, and named coverage owners** beat cream folklore.

Ordinary sick matrix: [sick-child coverage](/guides/dual-career-sick-child-coverage-singapore). Crusty sores: [impetigo exclusion](/guides/dual-career-kids-impetigo-school-exclusion-singapore). Throat bugs: [strep exclusion](/guides/dual-career-kids-strep-throat-school-exclusion-singapore). This guide is **ringworm / tinea exclusion ops**.

## Coverage products

| Product | Why |
| --- | --- |
| **Named daytime adult** | Scalp and body checks are not dual “later” |
| **GP / pharmacy fork** | Know when OTC cream fails and scalp needs a letter |
| **Written return clock** | Centre letters beat WhatsApp folklore |
| **Kit / towel sharing freeze** | Hats, combs, mats, and pool towels cascade |
| **Swim / PE / mats hold** | Shared floor and water spaces wait |

Clinical orientation: [NHS ringworm](https://www.nhs.uk/conditions/ringworm/) and [MOH](https://www.moh.gov.sg/). Early-childhood sector orientation: [ECDA](https://www.ecda.gov.sg/). Exclusion windows are **operator-specific** — follow the letter and the clinician plan.

## Dual-career playbook

1. Photograph the school exclusion / return rule into the shared channel within 15 minutes.  
2. Name today’s coverage owner before the first stand-up ([dual-career spouse](/guides/dual-career-spouse-singapore)).  
3. Book GP / paediatric review early if scalp is involved or OTC cream is not enough ([finding a paediatrician](/guides/finding-pediatrician-singapore)); do not invent forum steroid folklore.  
4. Put the written return clock on both calendars; protect one deep-work block for the non-coverage parent.  
5. Pause swim, shared mats, and borrowed hats until the hold lifts ([kids swimming & water safety](/guides/kids-swimming-water-safety-singapore)).  
6. Rewrite helper rest-day collisions if exclusion lands on a Sunday ([rest-day coverage](/guides/dual-career-helper-rest-day-sunday-coverage-singapore)).

## Traps

| Trap | Fix |
| --- | --- |
| “Cream started this morning” = cleared | Follow the written return clock |
| Both parents monitoring between Zooms | One coverage owner |
| Sharing hats / towels / yoga mats | Kit freeze day one |
| Sending a still-itchy child to PE mats | Written activity hold |
| Treating scalp like body cream folklore | Clinician plan for scalp |
